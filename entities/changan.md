# 长安汽车 (Changan)

## 概述
中国汽车集团，自主品牌销量领先。旗下拥有长安、深蓝、阿维塔、启源、启境等多品牌矩阵。2026年启源Q05累计销量突破10万台，与华为合作深入（启境品牌）。

## 2026年8月销量 + 阿维塔T09定名

### 阿维塔 T09（旗舰大型豪华SUV）
| 维度 | 参数 |
|------|------|
| 尺寸 | 5285/2025/1810mm，轴距3150mm，6座 |
| 智驾 | 华为乾崑 ADS 5（四激光） |
| 底盘 | 乾崑 XMC 数字底盘，后轮转向+蟹行 || 转弯半径 | 4米级 |

**判断**：T09是长安高端化+华为乾崑全栈的旗舰验证——四激光ADS 5首次量产上车。详见 [[huawei-auto]]。

### 天枢领航智驾系统（2026年9月发布）
9月18日，长安发布**央企首个一段式端到端智驾系统**：
| 维度 | 参数 |
|------|------|
| 技术路线 | 一段式端到端大模型 |
| 训练数据 | 超2000万段高质量驾驶数据 |
| 首搭车型 | 长安启源Q06（开启预售） |
| 行业背景 | L2辅助驾驶渗透率已达70.5%，但"高搭载、低使用"结构矛盾突出 |

**意义**：央企首个一段式端到端——长安在智驾技术路线上跳过传统的模块化方案，直接进入端到端赛道。与[[xiaomi-auto]]、[[xpeng]]等新势力的端到端路线形成对标。

## 长安×腾讯「AI火箭班」（2026年新合作）

### 合作模式
| 维度 | 内容 |
|------|------|
| 团队构成 | 长安24人（业务+技术骨干）+ 腾讯10人（产品/研发/交付专家） |
| 总人数 | 34人联合FDE团队 |
| 形式 | 脱产两个月，腾讯驻场长安 |

### 落地场景（7大核心业务）
1. **软件研发智能提效** - 代码生成、测试自动化
2. **新车产品策划辅助决策** - 市场分析、竞品对标
3. **采购合同智能审查** - 合同条款自动审核
4. **4S店智能客服** - 客户服务场景
5. **合同智审** - 合同管理
6. **智能客服** - 其他客服场景
7. **其他业务场景** - 持续扩展

### 腾讯角色
- 提供WorkBuddy和CodeBuddy平台
- 派专家驻场支持
- 联合开发、现场迭代

### 决策分工
- **腾讯主导**：技术决策（平台选型、Agent方案设计）
- **长安主导**：业务决策（场景定义、需求确认）

### 合作模式判断
这是一种"联合战队"模式——腾讯技术赋能，长安业务主导。与传统的供应商-甲方关系不同，更接近"嵌入式"合作。
