# 腾势全新N8

## 概述
比亚迪旗下腾势品牌全新 N8（2026-11 上市），以「**130kWh 电池 + CLTC 1003km**」续航为核心卖点的中大尺寸 SUV——「技术堆料换量」路线的代表车型。

## 关键配置

| 维度 | 内容 |
|------|------|
| 上市时间 | 2026-11（晨报口径 11/13） |
| 电池 | **130kWh**（CLTC **1003km**） |
| 动力 | 易三方三电机 **890kW** |
| 智驾 | 天神之眼 5.0（[[tianshen-eye-5]]） |
| 底盘 | 云辇-A（空气悬架） |

## 判断
- **续航破千 = 电池包规格军备竞赛的续集**：130kWh 大包 + 千公里 CLTC 是 2026 高端 SUV 的标配叙事（对照 [[li-auto-i6]] 96kWh 连山 5C 的「效率路线」——两种补能哲学：大电池长续航 vs 小电池快充）
- **易三方 890kW**：三电机扭矩矢量是比亚迪高端（[[yangwang]] 同源技术）下放的性能标签
- **腾势的品牌位置**：比亚迪「王朝（平价）+ 腾势（中高端）+ 仰望（超豪华）」矩阵的中坚——N8 用堆料守住 30 万级价格带，为 [[yangwang-dingyao]] 之下的价格锚点
