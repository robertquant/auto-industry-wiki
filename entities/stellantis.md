# Stellantis (斯特兰蒂斯)

## 概述
欧洲第四大汽车集团（标致/雪铁龙/菲亚特/欧宝等14品牌），[[leapmotor]]出海的关键合作伙伴。以「技术输出+本地化生产」模式引入中国性价比车型，是欧洲传统巨头中唯一把中国智造「引进欧洲本土生产」的玩家。

## 与零跑合作（Leapmotor International）

| 维度 | 内容 |
|------|------|
| 合作模式 | 技术输出+本地化生产（合资公司 Leapmotor International） |
| B10生产 | 西班牙萨拉戈萨工厂（2026年8月起） |
| 联合开发 | Opel C-SUV，共享平台 |
| 马德里工厂 | 2028 年（新增） |
| 品牌策略 | B10 将挂 **欧宝（Opel）标** |
| 战略意义 | 绕过关税壁垒，中国车在欧洲本土制造 |

## 2026-09-30 更新：神龙×Momenta 全球合作 + 中国供应链批量进入

- **神龙（东风系六方合资）× [[momenta]] 全球战略合作**：基于 R7 世界模型联合开发高阶智驾，**Jeep/标致全球车型**首搭——合资品牌从「自养团队」转向「买中国方案」，与大众 [[volkswagen]] 路线同构
- **博泰车联（02889.HK）进入 Jeep 全球供应体系**：高端智能座舱域控+AI车载交互，覆盖欧洲/中东/南美——**中国座舱供应链首次批量进入 Stellantis**，「中国研发、全球量产」
- **零跑意大利纯电市占率超25%**：Leapmotor International 首个突破性市场（见 [[italy-market-2026]]）
- **判断**：Stellantis 的「全球汽车联盟平台」角色进一步坐实——整车平台（零跑）+ 智驾（Momenta）+ 座舱（博泰）三层中国供应链全部入局，见 [[forecast-tracker]] 研判4
