# 启境汽车 (AISTALAND)

## 概述
启境智能汽车科技（广州）有限公司，广汽集团与华为乾崑深度合作打造的高端智能新能源汽车品牌。2026年3月由华望汽车更名而来，2026年5月完成超10亿元战略增资。

| 更名 | 2026年3月24日更名为启境智能汽车科技 |

### 品牌命名
- 中文「启境」：「启」=开启/首个，「境」=境界/领域 → 用技术拓展出行新空间
- 英文 AISTALAND = "AI Start New Land" → 用AI开启汽车出行全新境界
- 核心价值主张：MAKE DIFFERENCE（卓尔不凡）

## 华为合作模式（关键差异）

**华为乾崑首次全栈深度赋能大湾区车企**，与智选车模式（问界/智界）有本质区别：

| 维度 | 华为智选车模式 | 启境模式（乾崑深度赋能） |
|------|---------------|----------------------|
| 华为角色 | 产品定义主导、渠道赋能 | 技术全栈赋能、制造由广汽主导 |
| 团队配置 | 华为派驻团队常驻 | 华为派驻**数百人团队**常驻广州，合署办公 |
| 流程整合 | 部分整合 | 引入华为**IPD（集成产品开发）** + **IPMS（集成产品营销服务）** |
| 车企主导权 | 华为话语权强 | 广汽主导制造与品牌，华为技术底座提供 |

**判断**：启境模式更接近"华为技术供应商+车企主导品牌"的深度合作，而非华为亲自下场造车。广汽需要证明自己的品牌运营能力，华为需要证明技术赋能模式的可复制性。

## 竞争判断

### 优势
1. 华为技术背书：乾崑智驾+赤兔平台+896线激光雷达
2. 宁德时代+博世战略绑定：电池+智驾硬件两大核心供应链锁定
3. 广汽制造能力：成熟的整车研发、生产、品控体系
4. 品类差异化：猎装赛道竞争相对较小（极氪001、蔚来ET5T）

### 风险
1. 品牌冷启动：全新品牌，用户认知度为零
2. 华为赋能模式验证：非智选车模式，华为渠道赋能有限
3. 竞争格局：猎装品类虽小众，但极氪001已占据心智高地
4. 时间窗口：2026年新能源渗透率已过60%，新玩家需在红海中突围
