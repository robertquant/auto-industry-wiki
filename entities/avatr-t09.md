# 阿维塔 T09

## 概述
阿维塔旗舰车型，**2026年10月巴黎车展全球首秀**（10/12-18）。定位「华为乾崑首款高端旗舰」，是阿维塔（也是长安系）欧洲市场的第一印象车型。此前以「阿维塔9系」代号预热（见 [[avatr]]）。

## 核心配置（首秀披露）

| 维度 | 参数 |
|------|------|
| 智驾 | 华为乾崑 **ADS 5** |
| 感知 | **4颗激光雷达**（顶雷 **896线**，量产最高规格，同 [[shenxingzhe-8]]） |
| 动力 | 插混：1.5T 双电机 / 2.0T 三电机 |
| 首发地点 | 巴黎车展（10/12-18） |

## 战略意义

- **华为乾崑首款高端旗舰**：ADS 5 + 896线顶雷堆料，与 [[huawei-ads]] 高端化叙事绑定
- **巴黎车展全球首发即亮相**：长安×华为×宁德三方合作品牌在欧洲的第一印象（见 [[2026-paris-auto-show]]）
- 与 07L 构成阿维塔「纯电+插混」双线旗舰矩阵

## 判断

- 首秀时点微妙：欧洲正成为中国智驾「安全冗余」叙事的输出试验场（尊界刹车风波之后，见 [[zunjie-brake-pedal-controversy]]）——T09 的 4 激光雷达堆料既是技术卖点也是事故应对的「合规冗余」叙事
- 插混双电机/三电机布局：欧洲市场 PHEV 仍有窗口，但中欧混动出口协议（10/9，见 [[eu-hybrid-export-caps-2026]]）将压缩该窗口——本地化生产与否决定增量空间
