# 科大讯飞汽车 (iFlytek Auto)

中国智能语音与 AI 方案商（科大讯飞）的汽车业务线。车载语音市场长期份额第一，2026 年推出星火智慧座舱 3.0 + SparkAutoBOX 端侧方案，从「语音供应商」向「座舱 AI 系统供应商」升级。

## 2026-11-09 更新：星火智慧座舱 3.0 + SparkAutoBOX（11/9 发布口径）
- **前 8 月语音装机 436.1 万套、占比 42.7%**——车载语音装机霸主地位（对照 [[cockpit-supplier-ranking]] 座舱供应商榜单）
- **四系统 SOPHIA 架构**量产上车 **[[chery]] 奇瑞、魏牌（[[great-wall]]）、东风日产**——从单点语音到四系统（交互/座舱/车控/服务）架构输出
- **SparkAutoBOX 端侧盒子**：端云大模型 + 端侧 BOX 双形态——与 [[cockpit-model-tiering]]「小模型常驻车端」趋势同频

## 判断
- 42.7% 语音份额 = 存量基本盘；增量看「四系统 SOPHIA + 端侧 BOX」能否把语音单点优势升级为座舱 AI 系统订单（竞争对象从 [[volcengine]] 豆包、[[stepfun]] 等大模型方，到主机厂自研座舱）
- 与 [[cockpit-llm]] 大模型混战格局互补：讯飞卡位「语音入口 + 车规工程化」，是与互联网大模型厂商差异化的护城河
