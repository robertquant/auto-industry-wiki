# 奔驰 (Mercedes-Benz)

## 概述
德国豪华品牌，2026年战略转向「由中国定义、为全球输出」。MB.EA纯电平台首款量产车落地，与[[momenta]]（智驾合作）深度绑定中国供应链与智能化能力。2026年自我定位为「过渡年」。

## 纯电 GLC — MB.EA 首款量产车

| 维度 | 参数 |
|------|------|
| 平台 | MB.EA（首款量产） |
| 高压架构 | 800V |
| 续航 | CLTC 703km |
| 快充 | 22分钟 10%-80% |
| 智驾方案 | [[momenta]] 纯视觉（无激光雷达） |

**战略意义**：MB.EA是奔驰纯电转型的地基，GLC作为首款量产车验证平台与供应链。选用Momenta纯视觉方案=放弃自研智驾总成，承认中国方案商在端到端维度的代差。

## 中国化战略

- **「由中国定义、为全球输出」**：在中国的产品定义、供应链、智能化能力反向输出全球
- **端侧VLM**：与清华联研，上车新一代S级
- 智驾技术合作方：[[momenta]]（详见 [[bmw]] 同款合作）

### GLA EV（2026年9月发布）
| 维度 | 参数 |
|------|------|
| 平台 | MMA（Mercedes Modular Architecture） |
| 高压架构 | 800V |
| 续航 | WLTP 657km |
| 定位 | 紧凑型纯电SUV，入门级电动化 |
| 战略意义 | MMA是奔驰「入门电动化」的技术地基，覆盖GLA/GLB等紧凑级 |

### 电动C-Class匈牙利投产
电动版C-Class在匈牙利凯奇凯梅特工厂投产，标志着奔驰在欧洲的电动化产能布局进一步深入。匈牙利工厂也是宝马iX3长轴的主要海外产能基地，形成直接竞争。

**判断**：GLA EV（紧凑级）+ 电动C-Class（中级）组成奔驰2026下半年电动产品攻势的核心——MMA平台让入门级有了技术竞争力，但关键看定价能否对标宝马iX3的策略（26.99万起）。

## 历史与战略沿革

### 战略回调（2024年2月）
- 放弃"2030全电动化"激进目标，改为"按市场和客户需求灵活推进"，ICE和BEV双轨并行
- 战略判断：2022年喊"全电动"是被欧盟减排法规裹挟，2024年发现BEV需求不及预期后果断掉头，"哪个赚钱卖哪个"是务实选择

### 2026年产品攻势
- 计划推出18款新车——史上最大产品攻势
- 纯电CLA 260L中国上市，起售价22.9万元
- MB.OS系统由中国团队主导设计，接入豆包AI大模型，语音唤醒0.2秒

### 电动化平台进展
- **MMA平台**：纯电CLA已上市（800V高压、电耗12kWh/100km），两挡变速箱技术
- **MMA首款CLA首月销量仅千余辆**：不及预期，市场反应平淡
- **MB.EA Large架构暂停**：EQE/EQS后续车型取消，资源集中于MMA和MB.EA Medium
- **2025-2027年计划推36款新车**，MB.OS系统持续迭代

### 中国本土化
- 中国投资超140亿元，中国研发团队**2000人**规模，MMA平台100%本土化研发
- MB.OS中国团队主导交互设计
- 与[[momenta]]合作开发L2+智驾，搭载于新S级等多款车型
- 与[[catl]]、孚能科技合作满足中国电池安全新国标
- S级后排娱乐系统由中国开发，反向输出全球
- 相关概念：[[bba-ev-ranking-2026]]

### 市场表现
- 2025年在华销量同比下滑19%
- 2026 Q1在华销量11.16万辆，暴跌27%（全球最大跌幅市场）
- 纯电CLA中国月销仅21台（2026年2月），欧洲月均4000台

## 2026年时间线

### 5月中旬：旗舰智驾转向中国供应商
- 新一代S级搭载[[momenta]] L4智驾：首次将旗舰车型智驾交由中国供应商
- 2026年中国推超15款新车
- 战略意义：S级是品牌标杆，智驾交由中国供应商=中国智驾技术获顶级认可

### 5月下旬：弃用EQ品牌
- 纯电GLC不再使用EQ前缀，回归主品牌命名（详见下方9月命名重组）

### 6月：中国本土化进展
- 纯电GLC预售价**34.9万元**，2026年7月3日正式上市
- [[momenta]]合作：2017年投资，智驾合作深耕多年
- 判断：中国本土化团队强大，但产品力未转化为销量；Momenta合作时间最长，效果却不如后发者

### 6月下旬：价格下探
- 纯电CLA起售价调整至**25.9万元**，CLTC续航**866km**，智驾由中国团队主导
- 判断：德系豪华首次主动下沉至25万级主流市场；但25万级与30万+品牌调性存在张力

### 7月：高端电动化保守收缩
- **MB.EA Large平台开发停止**，仅保留MB.EA Medium（C-Class/GLC电动版）
- 判断：奔驰在德系三强中电动化态度最保守；放弃高端纯电平台意味着EQE/EQS时代的终结
- 对比BBA：宝马Neue Klasse切换最坚决，大众智驾本土化最深，奔驰收缩最明显

### 9月：命名体系重组（EQ前缀彻底退场）
- **GLB纯电版不再叫EQB**：放弃EQ前缀，回归主品牌命名逻辑
- **GLC EV汉诺威亮相**：借IAA Transportation主场发布纯电GLC
- **判断**：EQ品牌从「独立电动子品牌」到「事实退场」——奔驰电动线全面回归主品牌命名体系，与[[renault]]等欧洲车企的命名务实化一致。EQ后缀（EQA/EQB/EQC/EQE/EQS）作为品牌资产已被证伪
- **座舱架构**：奔驰 Momentum 模型采用分层架构——1个小模型常驻车端、其余云端按需唤醒（对比Jetta M6的3模型、特斯拉语音的2模型），详见 [[cockpit-model-tiering]]
