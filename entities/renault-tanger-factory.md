# 雷诺丹吉尔工厂

## 概述
雷诺丹吉尔工厂位于摩洛哥丹吉尔地中海港（Tanger Med）附近，是雷诺全球最大海外生产基地之一，也是雷诺集团效率最高的工厂。

## 系统化定位
丹吉尔工厂的核心优势在于嵌入Tanger Med综合体系：

```
港口 — 物流 — 工业 — 出口
```

制造到出口距离被压缩到极致：
- 零部件到港 → 工厂（几公里）
- 工厂 → 出口港（几公里）
- 平均物流时间大幅压缩

## 产能与产品
- 年产能：40万辆+
- 产品：Dacia Sandero、Dacia Logan、Dacia Duster
- 主要出口市场：欧洲、中东、非洲

## 战略意义

### 成本优势
- 人力成本远低于欧洲本土
- 物流效率最大化
- 自贸区税收优惠

### 地缘政治优势
- 避开欧盟针对中国的关税壁垒
- 摩洛哥与欧盟有自贸协定
- 为欧洲车企提供"近岸外包"选项

## 系统化思维启示
丹吉尔工厂不是单一工厂，而是嵌入**港口-物流-出口体系**的制造节点。这种系统化思维值得中国车企借鉴：
- 不要只建工厂，要建体系
- 物流效率决定成本竞争力
- 港口资源是制造布局的核心要素
