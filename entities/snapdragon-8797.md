# 高通骁龙8797 (Snapdragon 8797)

## 概述
高通 2026 年量产的旗舰舱驾融合芯片，是 SA8797 的正式量产版本，定位 25 万+ 高端车型。2026-09 确认量产，单芯算力约 **700 TOPS**，NPU 性能为上一代 12 倍，支持**端侧 300 亿参数 MoE** 大模型。

## 核心规格

| 参数 | 数值 |
|------|------|
| 单芯算力 | ~700 TOPS |
| NPU | 上代 12 倍性能 |
| 端侧大模型 | 支持 300 亿参数 MoE |
| 定位 | 高端舱驾融合（25 万+） |
| 量产时间 | 2026-09 确认量产 |

## 量产进展

- **零跑 D19 全球首发双 8797**：双芯方案算力约 **1280 TOPS**，为量产车最高舱驾一体算力之一。
- **8775 走量**：同代 8775 面向主流市场（[[snapdragon-8775]]，极狐 T5 首搭，144 TOPS），相较上代降本 20-30%。高通形成「8797 旗舰 + 8775 走量」双档产品矩阵。
