# 逸安启

## 概述
豪华品牌充电网络合资公司。2026-11 焕新后股权结构：**宝马 / 问界 / 奔驰 各 33.3%**——欧洲豪华双雄之外，中国品牌首次以平等股东身份入局豪华充电基础设施。

## 关键事实
| 维度 | 内容 |
|------|------|
| 股东 | 宝马 33.3% / 问界 33.3% / 奔驰 33.3% |
| 技术规格 | **800kW 液冷超充** |
| 当前规模 | 619 站 / 3,404 桩（截至 2026-11） |
| 2027 目标 | 1,000 站 |

## 战略解读
1. **「充电网络版合资」**：豪华品牌以基础设施合资绑定生态，而非整车合资——超充网络成为品牌服务体验的延伸（对照 [[catl]] 换电生态、[[ultra-fast-charging]] 车企自建站军备）
2. **问界入局的意义**：中国品牌（华为智选车体系）与欧洲豪华在补能基建上平起平坐——从「被授权使用」到「共建标准」的资格跃迁（[[wenjie]]、[[china-tech-reverse-export]]）
3. 800kW 液冷对标行业最高档（比亚迪兆瓦闪充 / 华为超充），豪华充电网从「够用」卷向「旗舰规格」
