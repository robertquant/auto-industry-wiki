# 高通骁龙8650（SA8650P）

## 概述
高通中阶智驾域控芯片，约 **100 TOPS** 算力档。2026 年成为 10-15 万价位带城市 NOA「标准答案」——同一颗芯片同时出现在新势力（零跑）、合资（东风日产）、日系合资（广汽丰田）三个阵营，是智驾成本下探的核心硬件载体。

## 为什么成为「标准答案」
- **算力友好**：Momenta R7 在 100 TOPS 跑通城市 NOA + 世界模型（[[momenta]]）——端到端模型不再依赖 500+ TOPS 旗舰芯片
- **成本结构骤降**：半固态激光雷达 2000-3000 元/颗（禾赛 ATX/速腾 MX 级）+ 8650 域控 3000-5000 元——整套智驾打包价被压到万元以内；NX7 Max→Ultra 差价仅 1 万（含雷达+域控+8295P+AR-HUD）
- **生态成熟**：与 [[qualcomm-auto]] 座舱 8295/8295P 同族系，8155→8295P→8650 算力梯度顺滑升级

## 判断
- 智驾成本下探 = **8650 中阶芯片 + 激光雷达白菜价 + Momenta 按量分成**三件事同时发生（2026-11-28）
- 8650 与旗舰 [[snapdragon-8797]]（~700 TOPS）、主流档 [[snapdragon-8787]] 构成高通「旗舰+走量+入门」三档矩阵；中阶城市 NOA 正在被「100 TOPS + 激光雷达」定义，而非「500 TOPS + 纯视觉」
- 对照 [[auto-chip-competitive-landscape]]：国产替代叙事之外，高通以「算力够用+价格低」守住入门-中阶盘
