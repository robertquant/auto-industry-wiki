# 新芯航途 (XHEART)

物理AI算力芯片公司，面向自动驾驶、机器人等场景研发「为大模型需求设计的专用芯片」。2026年10月完成战略轮融资，历史累计融资额约50亿元——**车企芯片资产资本化浪潮中，欧洲OEM以资本方式进入中国芯片生态的标志性案例**。

## 关键事实

| 维度 | 内容 |
|------|------|
| 定位 | 物理AI算力芯片（自动驾驶/机器人） |
| 战略轮时间 | 2026-10（10/16披露） |
| 累计融资 | 约50亿元 |
| 本轮投资方 | 雷诺（**首次投资**）+ 奇瑞（追加）+ 长鑫科技（国产存储龙头） |
| 核心产品 | X7——瞄准 L2++ 城区智驾及 L3/L4 市场 |
| 首发车型 | 上汽大众 ID.ERA 9X |
| 后续搭载 | MG、荣威（上汽系）、凯迪拉克（通用系）、奇瑞部分车型 |
| 合作伙伴 | Momenta（算法）、QNX（操作系统） |

## 战略解读

1. **雷诺「用资本买中国芯片」**：与[[renault]] ACDC 中国团队（<2年<2万欧标准化）同构——欧洲OEM不追赶中国芯片代差，直接入股锁定供应与定价权。对照 [[foreign-automakers-chinese-ad]] 的「技术合作外包」升级为「资本绑定」
2. **长鑫科技入股的供应链逻辑**：在 [[storage-chip-surge-2026]]（存储涨价180%）背景下，为芯片公司换取内存报价与供应优势——存储巨头向「有汽车背景的芯片公司」延伸，打通「算力芯片+存储」捆绑供应
3. **客户结构穿透三大阵营**：上汽（大众合资）、通用（凯迪拉克）、奇瑞——覆盖合资/外资/自主，与 [[xinchi-x10]]、[[wudang-c1296]] 等国产算力芯片在同一客户池竞争
4. **与理想马赫心科技同日呼应**（[[mahe-xintech]]）：车企/产业链芯片资产资本化进入「密集融资期」，智驾芯片战从产品竞争进入资本竞争阶段

## 2026-10-29 更新：X7 Ultra——模型-芯片协同而非堆算力
- **X7 Ultra：700 TOPS、NPU 利用率 98.7%**（盖世晚报）——算力绝对值不算高（对照 [[mahe-xintech]] 1280 TOPS 档），但 **98.7% 利用率指向模型-芯片协同设计**：智驾芯片竞争从「堆 TOPS」转向「每 TOPS 产出」（[[auto-chip-competitive-landscape]]）
- **X7 → X7 Ultra 双档**：覆盖 L2++（页首 X7 定位）与高阶两档市场；首发上汽大众 ID.ERA 9X 的量产验证进行中（[[volkswagen]]）
- 判断：98.7% 利用率是「为大模型需求设计芯片」（物理 AI 算力定位）的直接产物——与英伟达通用 GPU 的「利用率折损」形成路线差（[[physical-ai]]、[[nvidia]]）；若 ID.ERA 9X 实车验证达标，将是「模型-芯片协同」路线在合资体系内的首个量产样本
