# 方程豹钛9

方程豹品牌全尺寸旗舰 SUV，2026-10 官图预热。比亚迪首次用「承载式」平台做全尺寸插混 SUV——硬派越野品牌向城市家用扩张的试水之作。

## 关键事实

- **全尺寸承载式插混 SUV**——全新 DMS 平台（承载式），区别于方程豹既往非承载硬派路线（豹5/豹8/钛7）
- **轴距 3130mm**——超越 [[li-auto]] 理想L9（3105mm）、[[wenjie]] 问界M9（3110mm）
- 「城市家用」差异化定位：硬派品牌基因 + 家用全尺寸空间

## 战略解读

- 钛7（单月3.2万辆，见 [[byd]] 10/7 记录）验证「豹系列」平价放量能力后，钛9 向上试探旗舰价位——方程豹从「小众硬派」转向「国民全尺寸」双线
- 承载式 + DMS 平台 = 放弃越野极限、押注城市家用舒适——比亚迪对理想/问界霸占的 40 万+ 全尺寸市场正面进攻（[[9-series-suv-battle]]）

## 2026-10-20 更新：方程豹累计60万台 + 方程S/GT轿车入局 + 云辇-M首搭

- **累计销量突破 60 万台**（个性化品牌快速放量）
- **方程S 与方程S GT 轿车（9月上市）**：18.99-23.99 万元运动轿车，**首搭云辇-M 系统**，正面对标 [[xiaomi-auto]] SU7 / [[tesla]] Model 3——硬派品牌首次进入轿车市场（[[byd]] DMO 混动越野平台 + 云辇底盘技术）
- 与钛9（承载式全尺寸旗舰）构成「**硬派越野（豹系）+ 城市家用（钛系）+ 运动轿车（S系）**」三线扩张
- 相关：[[byd-han]]（云辇-A 对照——云辇家族从越野平台向轿车平台延伸）、[[sealion-06-dmi]]
