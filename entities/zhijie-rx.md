# 智界RX

华为×奇瑞智选车品牌[[zhijie]]的运动SUV旗舰，2026年9月上市、10/25 全国大规模交付启动。以「L3 架构标配硬件冗余」为差异化卖点，是华为系 L3 硬件预埋的先锋车型。

| 维度 | 数据 |
|------|------|
| 上市时间 | 2026-09-28 |
| 价格 | 25.98 - 38.98 万元；L3 架构版 31.98 万起 |

| 续航 | CLTC 最高 852km |
| 智驾 | 华为 ADS 5（WEWA 架构：弃语言中间层、多模态直出轨迹） |
| 感知 | 四激光雷达 + L3 架构八大冗余（896 线激光雷达 + 3 颗固态激光雷达，路测牌照申报口径 38 传感器） |
| 赛道纪录 | 浙赛 1:43.210，中国品牌量产 SUV 纪录 |

## 关键时间线

- **9/16 获 L3 路测牌照**：卡在强制国标 GB 44721-2026（2027/7/1 实施，[[l3-mandatory-standard]]）前的首个重点品牌路测；测试覆盖信号识别、紧急避险、最小风险策略七大场景
- **9/28 上市**：预售 24h 内「L3 架构版」订单占比超 90%；鸿蒙智行体系进入「车企主导、华为赋能」新阶段后首场发布会
- **10/25 全国大规模交付启动**（网通社/IT之家）：交付周期 4-6 周；**超 85% 大定用户选择 L3 架构版**（交付口径）

## 判断

1. **「L3 架构版」选装率 85-90% 是 2026 年最强的 L3 付费意愿实证**：消费者愿为冗余硬件（八大冗余/四激光雷达）买单——L3 从法规概念转化为产品差异化刚需（[[l3-autonomous-driving]]）
2. **法规卡位双刃剑**：2027/7/1 强标前属「营销性卡位」——硬件预埋已到位，但 L3 功能开放节奏仍受准入试点约束（第二批准入进行中，[[l3-mandatory-standard]]）
3. **对标与竞品**：直插 25-40 万运动纯电 SUV——特斯拉 Model Y 高性能版、小米 SU7 的高阶智驾版本（[[xiaomi]]）；华为 ADS 5 与 [[xiaopeng]] VLA 路线之争的旗舰载体之一
