# 马赫心科技 (Mach Heart Technology)

理想汽车旗下芯片子公司（上海马赫心科技，2026年8月注册），2026年10月16日完成首轮16.25亿元融资——**车企自研芯片资产独立资本化的首个样本**，投后估值最高171亿元，理想仍持股74.01%保持控股。

## 关键事实

| 维度 | 内容 |
|------|------|
| 成立 | 2026年8月注册（上海） |
| 首轮融资 | 16.25亿元（10/16签约） |
| 领投方 | 杭州经韬、蓝驰创投、华业天成（+启智资本参与） |
| 投后估值 | 追加认购权悉数行使达 **171亿元** |
| 理想持股 | 74.01%（控股） |
| 核心资产 | 马赫M100——**全球首款动态数据流AI芯片**（5nm车规、1280 TOPS） |
| 资金用途 | 芯片研发与商业化，尤其**非汽车领域**（机器人/域控等） |

## 战略解读

1. **芯片资产资本化公式确立**：理想复制「苹果式设计+代工」后，再把芯片部门独立融资——母公司保留控股权、外部资本（经韬/蓝驰/华业天成）为估值背书。对照同日 [[xinhe-hangtu]]（新芯航途50亿累计），车企芯片资产进入「密集融资期」
2. **「动态数据流」架构定位**：马赫M100区别于传统静态调度芯片，按数据流动态分配算力——对应理想 [[world-model]] 路线对高带宽、低延迟的刚性需求；已搭载新一代量产车型（[[li-auto]] i9/2026款i6）
3. **非汽车领域是第二增长曲线**：机器人/域控商业化目标——车企芯片子公司不再只服务整车，向 [[humanoid-robot-industry]] 等物理AI场景输出算力，与 [[nvidia]] 的「物理AI」叙事同赛道
4. **估值锚点**：171亿元投后 vs 理想汽车整体——自研芯片从「成本中心」向「独立估值单元」转化，为后续分拆上市预留通道
