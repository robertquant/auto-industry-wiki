# 极氪 (Zeekr)

## 概述
吉利集团旗下高端新能源品牌，定位30万+豪华市场。2021年成立，目前是中国品牌高端化最成功的案例之一。

## 战略定位

### 高端化成功的原因
1. **产品力硬核**：浩瀚架构、三电技术、性能标杆
2. **价格带精准**：30-50万区间，避开BBA入门但有溢价空间
3. **用户转化**：80%+来自传统豪华品牌，说明品牌认可度高
4. **交付提速**：供应链问题解决后，Hyper版从等数月缩短到5-8周

### 与银河的关系
- **银河**：10-15万级，走量性价比路线
- **极氪**：30-50万+级，高端豪华路线
- 两者**不是内卷关系**，而是覆盖不同价格带的协同布局

## 2026-09-30 更新：9X 出海 + 8月数据

### 极氪9X 出海——「最贵中国车」
- **SEP超级电混**（Super Electric Power）：9X 出海版动力核心，混动架构适配海外补能环境
- 定价：阿联酋售超 **80万人民币**、欧洲近 **100万**——中国品牌史上最高出海定价，正面刚保时捷/劳斯莱斯
- 规模：已进入 **60+ 国家**、门店近 **800家**
- **判断**：9X 出海不是「卖车」而是「立价」——用旗舰价格带重构中国品牌在海外的价值锚点，与 [[chinese-oem-export]] 的走量逻辑（奇瑞/比亚迪）形成高低两线
