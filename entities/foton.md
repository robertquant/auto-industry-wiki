# 福田汽车 (Foton)

## 概述
北汽集团旗下商用车龙头（轻卡/重卡/客车），中国商用车销量规模最大的车企之一。2026-10-08/09 与卓驭科技签署战略合作，切入**商用车高阶智驾**——商用车成为智驾下一个价格洼地。

## 2026-10-08 战略签约：福田 × 卓驭

| 维度 | 内容 |
|------|------|
| 合作方 | [[zhuoyu]]（原大疆车载，低成本智驾方案商） |
| 方向 | 商用车高阶智驾 |
| 背景 | 卓驭从乘用车方案商切入商用车赛道 |
| 逻辑 | 卓驭低成本方案 + 福田规模 = 典型「降维切入」 |
| 行业意义 | 商用车是智驾渗透率洼地：行驶场景相对封闭（干线/港口/矿区）、人工成本占比高、安全法规驱动强 |

## 战略判断
- 商用车高阶智驾（干线物流 NOA、港口/矿区无人驾驶）是继乘用车城市 NOA（[[city-noa]]）之后的下一个放量场景
- 与乘用车路线（华为乾崑、[[momenta]]）相比，商用车更吃「成本 + 场景适配」，正中卓驭性价比路线靶心
- 竞品对照：华为乾崑亦有商用车布局；地平线（[[horizon-robotics]]）在商用车芯片侧渗透

## 关系网络
