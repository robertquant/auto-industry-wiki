# 吉利汽车 (Geely Auto)

## 概述
中国自主品牌龙头之一，2026年H1收入1736亿元，核心归母净利润96.8亿元。2026年8月完成重大管理层交接：李书福辞任董事会主席，安聪慧接任。战略转向纯电高压超快充，不再研发传统燃油动力总成。

### 8月交付明细 + 全年目标（9/26）

| 品牌 | 8月 | 同比 |
|------|-----|------|
| 极氪 | 36,981 | +109.8% |
| 领克 | 17,027 | -37%（新能源渗透 91%） |

- **2026 目标**：集团 **345 万辆**，中国星全面转 i-HEV
- **银河E5**：800V+6C，限时 **9.78 万起**

**判断**：极氪高端放量、领克燃油基盘收缩（-37%）但新能源渗透已达 91%——吉利「减法」进入尾声，全年目标靠纯电高压 + 出口兑现。

### 9月动态
- **极氪正式并入吉利汽车**：IPO不到600天即完成私有化退市。极氪2021年4月成立，2024年11月纽交所上市，2026年9月私有化退市，上市时长不足600天——成为近年中概股最短上市纪录之一。品牌矩阵从最高峰缩减至**4个**（吉利/银河/极氪/领克）。
- **重庆耀宁出售**：国家市场监管总局批准[[catl]]收购吉利系重庆耀宁新能源股权。吉利称未放弃自研电池，强调该工厂只是「电池战略中的一个小动作」。同日银河战舰700开启预售（19.98万元起），全系搭载宁德时代6C快充电池——形成「卖厂给宁德+采购宁德电池」的复杂信号。
- **银河战舰700**：3月11日开启预售，起售价19.98万元，全系搭载宁德时代6C快充电池。

### 银河TT上市（2026年9月10日）
| 维度 | 参数 |
|------|------|
| 定位 | C级AI纯电运动轿车 |
| 价格 | 12.99-18.59万元（限时先享价） |
| 电气 | 全系标配800V + 宁德时代神行TT 6C超充电池（11分钟补能近500km） |
| 电驱 | 雷霆16合1电驱 |
| 智驾 | 千里浩瀚G-ASD高阶智驾，全系标配激光雷达，支持城区CNOA |
| 底盘 | 路特斯调校，Ultra版「Handling by Lotus」认证 |

**判断**：银河TT是吉利在15万级纯电市场的重拳——800V+6C超充+激光雷达智驾在13万价位段，直接对标[[xiaomi-auto]]SU7和小鹏G9L。与[[changan]]启源Q06（12万级端到端智驾）形成正面竞争。

### 阶跃星辰深度绑定
吉利与[[stepfun]]的绑定已超出普通供应商关系：李书福个人直接投资+印奇任阶跃星辰董事长。详情见[[stepfun#与吉利深度绑定]]。

### 领克欧洲独家经销：与[[volvo]]签署最终协议，自2027年1月起沃尔沃作为领克在欧洲的独家经销商。吉利继续负责产品设计、研发与品牌战略。不涉及股权变化。

**判断**：重庆耀宁出售被外界解读为吉利自研电池的退步信号，但吉利实际在用「多供应商+自研并行」的策略平衡成本和风险——与理想的自研战略形成对照。

**判断**：出海占比升至38%，吉利从规模驱动转向利润驱动——单车收入+12.8%印证高端化与出口双引擎。出海分析见 [[chinese-oem-export]]。

### GTC 2026：超级Eva + G-ASD 4.0

- 首发车型：极氪8X
- 详见 [[cockpit-llm]] 座舱大模型格局

## 战略转型

### 组织调整（"两年减法"）
- 几何并入[[geely#银河]]品牌
- [[zeekr]]整合[[zeekr-lynk-co-merger|领克]]并私有化
- 产品项目削减20%以上

- **不再研发传统燃油动力总成**
- 纯电全部押注高压超快充
- 与[[nissan]]研发周期改革形成对比

### 海外战略
| 维度 | 数据 |

## 2026-10-04 更新：2026目标345万辆 + 英伟达共研L4

- **2026年目标：345万辆（+14%）、出口 64万辆（+52%）**——出口增速近3倍于总量增速，出海是最大增量引擎（对照 [[chery]]、[[byd]] 出海三极格局，见 [[chinese-oem-export]]）
- **超级Eva + 千里浩瀚 G-ASD 4.0 量产上车**（见 [[geely-super-eva]]）；**与英伟达 DRIVE Hyperion 共研 L4**——智驾双轨：自研G-ASD走量、英伟达平台攻L4
- 领克 9月 18,493台、新能源占比创新高（合并后 [[zeekr-lynk-co-merger]] 高端矩阵放量）
- 判断：345万目标 = 基盘（吉利+银河+领克极氪）+ 出海（64万）双轮；与英伟达共研说明L4级智驾仍需要外部算力底座，自研芯片+外购平台并行是头部车企的务实路线

## 2026-10-10 更新：官宣进军加拿大（2027首批车型）

- **吉利正式宣布进入加拿大市场**：2027 年首批车型，依托**中加低关税 EV 配额（4.9万辆/年、6.1%关税）**——北美闸门唯一的合规缝隙（见 [[north-america-ev-trade-barriers-2026]]）
- 玩家卡位：路特斯先行、**吉利**官宣（2027）、比亚迪/奇瑞筹备、特斯拉抢配额——配额是「稀缺合规凭证」
- 判断：吉利北美攻略走「配额通道+轻资产」路线（延续 H1 出口 47.4万辆的轻资产逻辑）；加拿大是北美唯一可合规进入的市场，2027 年首批车型的成败决定后续配额分配话语权（对照 [[tesla]] 抢配额、[[polestar-us-ban-2026]] 美国禁令参照）
