# 蓝固新能源

## 概述
中国固态电解质材料商，2026年11月完成近2亿元B+轮融资，资金重点投向固态电解质研发与产业化。多基地多路线布局成型，是 [[solid-state-battery]] 产业链上游的关键卡位者。

## 融资与产能（2026-11）

| 维度 | 内容 |
|------|------|
| 轮次 | B+轮，近2亿元（2026-11-06披露） |
| 投资方 | 中化学新材料基金、常州新能源产业基金等 |
| 溧阳基地 | 万吨级氧化物固态电解质产线已投产 |
| 溧阳基地 | 百吨级全固态电解质产线稳定运行 |
| 遂宁基地 | 千吨级全固态电解质产线启动建设 |

## 战略判断
- **氧化物+全固态双路线并行**：溧阳氧化物产线走量产、遂宁/溧阳全固态线卡下一代——覆盖「过渡态+终局态」两条技术窗口
- 与 [[guangwan-jiyan]]（深共熔基复合固态电解质、吉瓦时级产线）同属固态电解质产业化第一梯队——电解质是固态电池价值量最高、最难的部分，材料商正在抢先锁定产能与客户
- 对照 [[svolt]]（半固态电池包量产）：「材料先行」vs「电池包先行」的两条固态产业化路径
