# 元戎启行 (DeepRoute.ai)

## 概述
中国自动驾驶技术公司，2026年以VLA量产突破和高通双平台合作成为行业焦点。基于高通SA8650/SA8797双平台，实现VLA模型规模化车端部署，是"轻舟已过万重山"策略的典型代表。

## 2026年关键动态

### 6月涨势分析
**三个核心驱动因素**：

1. **零跑合作落地**：A10车型单月销量2.6万+，搭载元戎启行智驾方案
2. **高通峰会亮相**：双平台（SA8650/SA8797）量产成果分享，行业影响力提升
3. **VLA量产突破**：VLA模型首次规模化车端部署，技术成熟度获验证

### 技术方案

| 维度 | 内容 |
|------|------|
| 芯片平台 | 高通SA8650（50/100 TOPS）+ SA8797（舱驾一体） |
| 智驾方案 | VLA端到端模型 |
| 量产车型 | 零跑A10（月销2.6万+） |
| 功能覆盖 | 城区NOA，支持"车位到车位"全场景 |
| 实测表现 | 接近第一梯队 |

### 高通双平台策略
| 平台 | 定位 | 元戎角色 |
|------|------|---------|
| SA8650 | 纯智驾芯片（50/100 TOPS），中端车型 | 软件算法适配 |
| SA8797 | 舱驾一体芯片，高端车型 | 软件算法适配 |

## 竞争定位

### 优势
1. **量产落地速度**：零跑A10大规模验证，月销2.6万+非小规模POC
2. **高通生态绑定**：深耕高通平台，避开英伟达生态正面竞争
3. **VLA先发**：VLA模型规模化车端部署，国内领先
4. **性价比路线**：SA8650平台成本优势，适配15万级市场

### 风险
1. **技术壁垒**：VLA模型能力天花板取决于高通芯片算力
2. **客户单一**：零跑为主要客户，客户集中度风险
3. **竞争格局**：大疆车载、华为、Momenta均在高通平台布局
4. **英伟达生态**：Thor平台2000 TOPS算力优势难以忽视
