# 吉利超级Eva座舱Agent

## 概述
吉利在 **GTC 2026** 发布的座舱 AI 方案「**超级 Eva**」，与智驾系统 **G-ASD 4.0** 同台，基座模型为[[stepfun]]（阶跃星辰）**Step 3.5 Flash**，首发车型为极氪 8X。代表传统车企「座舱 Agent + 外部大模型」的落地路径。

## 战略意义

- **绑定而非自研**：吉利与[[stepfun]]的绑定超出普通供应商关系（李书福个人投资 + 印奇任董事长），座舱 Agent 直接建在阶跃基座上——与[[li-auto]]（Mind GPT 自研+备案）路线不同，属「深度绑定外部模型」派。
- **舱驾同台**：超级 Eva（座舱）+ G-ASD 4.0（智驾）同台发布，是[[cabin-drive-integration]]（舱驾融合）在软件层的体现。
- **座舱 Agent 竞争焦点**：从「比谁会聊」转向「比谁能干活」——真正壁垒在底层车载基础软件（把一句话变一串可靠动作），参见 [[cockpit-ai-barrier-layering]]。
