# 宝马i3 50L

## 概述
宝马新世代（Neue Klasse）纯电 3 系长轴版（中国特供 50L 家族成员），2026 年 11 月以「一次充电实测 1,213km」创宝马电动车单次行驶距离纪录。与 iX3 50L 构成宝马中国长轴纯电「50L 家族」。

## 关键数据（中国真实道路挑战，11/4 Electric Cars Report）

| 维度 | 数据 |
|------|------|
| 实测续航 | **1,213 km**（一次充电，宝马电动车纪录） |
| CLTC 标称 | 1,028 km |
| 达成率 | **118%**（超标称 18%） |
| 平均电耗 | 8.8 kWh/100km |
| 电池包 | 113.4 kWh |
| 路况 | 高速/国道/乡村/城市混合 |
| 完成状态 | 剩余 1% 电量 |

## 技术判断
- **CLTC 达成率 118% = 真实道路效率背书**：中国长轴 + 大电池是「账面续航」路线，但 8.8kWh/100km 的电耗（同级极低）说明能耗做减法才是核心——与 iX3 50L（2026 年 8 月沈阳→北京 1,030.2km 实测，见 [[bmw]]）同一套「中国路况实测」打法
- 效率叙事补齐德系短板：同日 [[mercedes-benz]] 发布 800V 恒压 Power Converter（[[800v-platform]]），德系双雄同一周集中打「效率牌」——欧洲豪华在中国长轴纯电上的竞争焦点从续航数字转向能耗与补能兼容性
- 关联：G58（第八代 3 系长轴）在第 413 批工信部公示中首次落地新世代设计语言——3 系基盘同步切换 Neue Klasse 视觉，与 i3 50L 同属新世代平台期产品
