# 高通骁龙8787 (Snapdragon 8787)

## 概述
高通在 2026 年新增的**舱驾融合**芯片，定位介于走量的 **8775** 与旗舰 **8797** 之间，核心卖点是「对标 8295 座舱 + ADAS 双芯」的整合方案，直攻 **15-25 万元**主流价位带。与 8797（旗舰）/8775（走量）共同构成高通三档舱驾融合矩阵。

## 定位与规格

| 参数 | 内容 |
|------|------|
| 定位 | 15-25 万主流价位带 |
| 对标 | 「8295 座舱 + 独立 ADAS」双芯方案 |
| 形态 | 舱驾融合单芯片 |
| 代际关系 | 8797（旗舰）> 8787（主流）> 8775（走量） |

## 战略意义

- **补齐价位带**：8797 卡 25 万+、8775 卡入门，8787 填 15-25 万主流——这正是[[cabin-drive-integration]]（舱驾融合）放量的核心战场。
- **正面竞争**：在 15-25 万价位带与[[horizon-robotics]]星空 6（650 TOPS，5nm）直接对位，也承接 8295 存量座舱车型的「座舱+智驾」升级需求。
- **降本逻辑**：单芯片替代「座舱域控 + 智驾域控」双芯，减少一套 DDR——驱动力同[[storage-chip-surge-2026]]与[[advanced-node-capacity-2027]]。
