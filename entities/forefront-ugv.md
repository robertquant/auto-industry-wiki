# Forefront 军用无人地面车

## 概述
2026年11月3日，雷诺与比利时军工企业 John Cockerill（约翰·科克里尔）联合发布的**军用无人地面车（UGV）概念**——雷诺「防务攻势」从概念走向实车的标志性产品。法国军方参与开发，计划数周内进入军事试验。

## 关键参数

| 维度 | 参数 |
|------|------|
| 发布 | 2026-11-03（Renault × John Cockerill） |
| 驱动 | 四驱四转向（4WD/4WS） |
| 动力 | 双电机 |
| 续航 | ~400km，可增程（range extender） |
| 载重 | 1 吨 |
| 军方参与 | 法国军方 |
| 试验节奏 | 数周内军试 |

## 战略意义
- **雷诺「防务攻势」延续**（Automotive News 11/4 定性）——汽车制造能力外溢军工的第二落点：此前已与泰雷兹合作无人机（月产 1000 架，见 [[renault]]），从「零部件级产能外溢」升级为「整车级防务产品」
- 与 [[ice-supplier-divergence]] 的「产能二次定价」逻辑同构：产能过剩时代，OEM 把大规模制造能力出售给国防部门
- 判断：雷诺在「本土防守+平价电动进攻」（[[renault]] 主线）之外开辟**第二条增长曲线（国防/特种车）**——民用电动承压期的对冲叙事，军试结果是下一验证点
