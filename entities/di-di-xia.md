# 迪迪虾 (比亚迪超级智能体)

## 概述
比亚迪于 2026-09-14 发布的超级智能体，是比亚迪首个打通**跨应用自动执行**能力的座舱 Agent。基于**通义千问**（阿里云大模型）+ 阿里生态（飞猪、淘宝闪购），首搭车型为**腾势 N8L**。

## 核心能力

| 维度 | 内容 |
|------|------|
| 底座模型 | 通义千问（阿里云） |
| 生态接入 | 飞猪、淘宝闪购等阿里生态 App |
| 代表能力 | 跨应用自动执行（如「订酒店 + 导航」一次指令闭环） |
| 首发车型 | 腾势 N8L |
| 发布时间 | 2026-09-14 |

## 判断
- **从「聊天」到「执行」**：迪迪虾的关键不是语音交互，而是 Agent 直驱 App 完成任务——把座舱 AI 从问答升级为「数字员工」，与 [[cockpit-llm]] 的「Agent 终局 = 可信执行」判断一致。
- **生态绑定的双刃剑**：比亚迪选择阿里生态（而非自研基座模型），与吉利「自研体验层 + 外采基座」路线对照，本质是把座舱服务能力外包给互联网生态——短期上车快，长期模型护城河薄弱。
- **自主品牌规模优势**：比亚迪以千万级保有量为 Agent 提供真实任务分布，是垂直整合之外的数据壁垒。
