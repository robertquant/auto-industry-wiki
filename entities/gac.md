# 广汽集团 (GAC)

## 概述
中国六大汽车央企/国企集团之一，总部广州。与本田（广汽本田）、丰田（广汽丰田）两大日系合资企业深度绑定，自主板块拥有传祺、埃安（AION）。2026年经历合资崩塌与自主补位的行业大变局，处于合资资产重组的中心。

## 关键事件：收购一汽丰田50%股权（2026-09-28）

| 维度 | 内容 |
|------|------|
| 方案 | 广汽集团拟**发行股份收购一汽丰田50%股权**（重组预案） |
| 市场反应 | 复牌一字涨停、封单超6.5亿元 |
| 落地影响 | 广汽将**同时掌控南北丰田两大合资主体**（一汽丰田+广汽丰田） |
| 产销安排 | 生产端归广汽，新销售公司三方持股 |
| 行业意义 | 传统合资体系从「各自为战」转向**资产、产能、渠道重新整合**；「南北丰田产销分离」 |

**判断**：日系合资在华衰退期（见 [[japanese-sales-china-2026]]、[[honda-china]]），广汽反向加码丰田资产——本质是**用股权整合锁定合资残值**，与 [[saic-gm]] 续约至2047形成对照：一个是「抱紧外资续命」，一个是「主动收编产能」。丰田体系整合后，广汽将成为中国最大的日系合资运营方。

## 2026-10-07 更新：一汽丰田辟谣 + 整合筹码博弈
- **一汽丰田 10/5 辟谣**「退出中国/大降价」——广汽收购预案（9/28）后的传闻管理动作；整合方案未定，处筹码博弈期（[[toyota]]）
- 南北丰田「产销分离」执行路径明确：生产归广汽统筹、销售 50:25:25 三方新公司——交易落地前核心变量是定价与审批
- 判断：辟谣不改变整合方向，但渠道/员工情绪是执行风险；广汽需在「接盘产能」与「自主聚焦」间找平衡（[[central-soe-restructuring-2026]]）

## 2026-10-09 更新：一汽/丰田/广汽三方签约（10/8）

- **三方正式签约**：广汽购一汽丰田 50% 股权落地推进——从 9/28 重组预案进入执行阶段，南北丰田协同（[[toyota]]）
- 方案沿用「产销分离」：生产归广汽统筹、销售 50:25:25 三方新公司
- 判断：交易从「预案博弈」进入「执行落地」——剩余变量是定价、审批与渠道整合节奏；广汽将成中国最大日系合资运营方（对照 [[saic-gm]] 续约至 2047）
## 2026-10-11 更新：三方签约细节——「全面协同」定调
- **10/8 广州正式签约**：广汽拟**发行股份购买一汽丰田 50% 股权**，交易完成后一汽丰田仍独立运营，**中国一汽将成广汽重要战略股东**——双向股权绑定（广汽拿产能、一汽拿广汽股权）而非单边收购
- 一汽丰田与广汽丰田将在**研发、采购、生产、销售环节全面协同**、加速电动化与智能化布局——「产销分离」（10/1）之上再叠「研发协同」，整合从股权层进入经营层（[[toyota]]）
- 判断：合资整合进入「执行期」——全面协同是「统一体收缩」的操作细则；广汽成为南北丰田整合的枢纽角色（对照 [[saic-gm]] 续约式防守，广汽是进攻式收编）

## 2026-10-16 更新：因湃电池第30万套下线——电池全栈自研闭环

- **广汽自研因湃电池第 30 万套下线**（10/16 盖世）：2011 年电池系统/BMS 研发起步，走通材料-电芯-PACK 全栈自研自产，弹匣电池技术迭代，已适配埃安 i60/N60/UT 等——整车央企中少有的电池全环节自主可控样本（[[battery-white-box]] 白盒化趋势）
- 判断：因湃产能爬坡 = 广汽在「合资整合（一汽丰田股权）+ 自主电池」双线加注；30 万套规模 vs [[catl]]/[[byd]] 仍是自供角色，但对埃安成本曲线是实打实的下探（[[auto-price-hike-2026]] 语境）
