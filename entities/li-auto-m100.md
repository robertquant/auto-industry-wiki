# 理想马赫M100芯片

理想汽车自研智驾芯片，单芯算力1280 TOPS，5nm工艺，利用率达82%。

## 核心参数

| 参数 | 规格 |
|------|------|
| 算力 | 1280 TOPS（单芯） |
| 制程 | 5nm |
| 利用率 | 82% |
| 定位 | 车企自研芯片旗舰 |

## 行业背景

理想马赫M100是车企自研芯片浪潮的代表产品之一。2026年车企自研芯片进入量产期：
- [[byd-xuanji-a3]] - 比亚迪璇玑A3，4nm，700 TOPS
- [[nio]] - 蔚来神玑NX9031，搭载乐道L60中高配
- [[xiaopeng]] - 小鹏图灵芯片
- [[li-auto]] - 理想马赫M100

## 竞争格局

车企自研芯片对应冲智驾供应商格局：
- [[nvidia]] Orin X 在华份额从39%降至25%
- [[horizon]] 地平线基础ADAS份额达47.7%，征程6P单芯560 TOPS

## 技术意义

1. **算力突破**：单芯1280 TOPS超越双Orin X方案
2. **利用率领先**：82%利用率远超行业平均60-70%
3. **成本可控**：自研降低对外依赖，提升供应链议价权

## 2026-10-18 更新：马赫M100 动态数据流定位 + 子公司资本化

- **马赫M100 确认为「全球首款动态数据流AI芯片」**（5nm 车规/1280 TOPS），已搭载新一代量产车型（i9/2026款i6）——动态数据流 = 按数据流动态分配算力，区别于传统静态调度，对应 [[world-model]] 高带宽低延迟需求
- **母公司 [[li-auto]] 将芯片业务独立为上海马赫心科技（2026年8月注册）并完成首轮 16.25 亿融资**，投后估值最高 171 亿元、理想持股 74.01%（详见 [[mahe-xintech]]）
- 资金投向含非汽车领域（机器人/域控）——M100 架构从智驾向 [[humanoid-robot-industry]] 等物理AI场景延伸
