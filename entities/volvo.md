# 沃尔沃汽车 (Volvo Cars)

## 概述
瑞典豪华汽车品牌，2010年被[[geely]]收购后进入吉利生态体系。2026年迎来在华业务关键转折：大中华区换帅、中国区销量暴跌、承接领克欧洲经销商角色。

## 2026年9月关键动态

### 大中华区换帅
| 维度 | 内容 |
|------|------|
| 新任 | 何阔（Michael He）任大中华区销售公司总裁（9月8日起） |
| 前任 | 于柯鑫离职 |
| 何阔背景 | 20余年豪华品牌经验，先后任职奔驰、宝马、英菲尼迪 |
| 高管变动 | 2026年第二次核心管理层调整（5月段建军接替袁小林任大中华区总裁） |

### 领克欧洲独家经销（2027年起）
| 维度 | 内容 |
|------|------|
| 生效时间 | 2027年1月 |
| 角色 | 领克在欧洲的独家经销商 |
| 品牌运营 | 沃尔沃承担 |
| 吉利角色 | 继续负责产品设计、研发与品牌战略 |
| 股权变化 | 不涉及 |
| 战略意义 | 复用沃尔沃欧洲渠道网络，降低领克自建渠道成本 |

## 在华困境

| 维度 | 2025 | 2026 H1 |
|------|------|---------|
| 销量 | ~10万辆级 | 约5万 |
| 新能源产品 | 无纯电主力 | 纯电布局缓慢 |
| 价格体系 | 持续承压 | 保价优先 |
| 燃油车份额 | 持续被挤压 | 加速下滑 |

**判断**：沃尔沃在华进入"保利润、稳渠道"的防御阶段。不同于大众通过合资加速智能化（[[volkswagen]]的酷睿程+小鹏合作），沃尔沃缺乏本土化技术深度——这是"保价优先"策略的技术本质原因。
