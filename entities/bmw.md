# 宝马 (BMW)

## 概述
德国豪华品牌，2026年5月完成掌门人更替（齐普策→聂科维）。押注中国智驾供应链（与[[momenta]]深度共研）实现智能化跃迁，iX3长轴以「900km续航+26.99万起」成为欧洲品牌在华电动化标杆。成都车展智驾平权代表作。

### Neue Klasse iX3大获成功
Neue Klasse平台首款车型iX3市场反响超预期——订单逼近10万辆。Neue Klasse是宝马的下一代纯电平台，iX3的成功验证了宝马「中国智驾+欧洲底盘调校」路线的市场接受度。详见[[chinese-oem-export#反向技术输出]]。

### 10/5 补充：新世代 iX3 沈阳量产确认
- **新世代 iX3 确认 2026 下半年沈阳量产**（800V + CLTC 900km，[[momenta]] 中国专属智驾）——Neue Klasse 首次落地中国产能，验证「中国智能化+中国制造」双本地化
- **i3 年内推出**（长轴 CLTC 超1000km）；**全年中国 20 款新车**
- **全球纯电累计交付破 200 万辆**：宝马纯电规模的集团级里程碑
- **判断**：iX3 沈阳量产 = 宝马把「欧洲豪华 × 中国供应链」公式从产品层推进到产能层，与 [[volkswagen]] 安徽基地（月交付仅1,716台）形成同一路径的两种节奏

**判断**：Neue Klasse的成功不仅是车型成功，更是「欧洲品牌=中国智能化+欧洲底盘调校」组合公式的验证，对[[mercedes-benz]]和[[volkswagen]]有标杆参考价值。

## 反对欧盟对华加税（2026-09-24）
- 宝马 CEO 公开反对欧盟对中国电动车加征关税

**判断**：宝马在华利益（沈阳长轴 iX3 产能 + 中国市场销量）远大于欧洲本土保护收益，反对加税是利益驱动的必然。与大众/奔驰的立场共同构成德系与法国、意大利阵营在贸易政策上的分裂。参见 [[bmw]] 中国化路线、[[chinese-oem-export]]。

## 与Momenta深度共研

- **R7世界模型**：宝马×[[momenta]]联合方案的核心
- **数据基础**：150亿公里中国道路数据
- **模式判断**：欧洲豪华品牌放弃智驾自研，全面外包中国方案商——与[[mercedes-benz]]（Momenta纯视觉）同路径

## 竞争定位

- 26.99万起+900km续航：直接冲击新势力30万级价位段
- 智驾平权（端到端全系标配）：「油改电时代」结束，进入「欧洲品牌=中国智能化+欧洲底盘调校」组合竞争时代

### iX3 中国申报与交付（2026-09-25）
- **9/8 申报完成**：iX3 长轴版中国工信部申报完成，**11 月交付**，轴距加长 **+108mm**
- **ADAS**：用 [[momenta]] 端到端方案
- **座舱**：集成阿里 LLM / [[deepseek]] / 华为 HiCar 三方案
- **判断**：与奔驰（[[mercedes-benz]]）同为“欧洲豪华品牌+中国智驾供应商”组合，宝马在座舱上更开放（三方案并行）

### 中国版 iX3 + 智驾/氢能规划（9/26）
- **iX3 中国版**：沈阳产，轴距 **3,005mm**，CLTC 破 **900km**，Q4 交付
- **智驾**：与 [[momenta]] 端到端「飞轮」方案（L2++），2027 底覆盖 **12 款**车型
- **氢能**：iX5 Hydrogen **2028** 首发

**判断**：宝马在纯电（Neue Klasse）、智驾（Momenta）、氢能（iX5）三线并行，是德系中技术路线最分散的一家。

## 2026-10-01 更新：资本市场日——渠道裁撤20% + 沈阳出口审查

- **裁撤 20% 中国渠道** + 推行统一价格体系——告别价格战内耗，渠道瘦身换毛利
- **审查沈阳基地出口全球潜力**：华晨宝马从「中国内销」升级为「全球出口基地」候选——中国制造成本+地缘关税下的新选项
- 背景：iX3长轴 26.99万一口价策略与本次渠道改革同频（见 [[2026-09-china-sales-battle]]）

## 2026-10-02 更新：i3长轴1000km+ + 沈阳电池智控试生产

- **i3 长轴 CLTC 1000km+、全系800V**——Neue Klasse 续航标尺再抬高（vs [[mercedes-benz]] 纯电GLC 703km，差距300km级）
- iX3 长轴 11月交付、入门版LFP，26.99万一口价（见 9/30 更新）
- **德国工厂三班倒 24/7 生产**；沈阳基地同步启动新一代电池智控系统试生产
- 判断：「中国降本+德国满载」双基地模式成形，i3长轴把纯电豪华续航竞争带入 1000km 时代

## 2026-10-03 更新：新世代 iX3 开启预订

- **新世代 iX3 26.99万起开启预订**——Neue Klasse 首款车进入订单转化阶段（11月交付、入门版LFP）
- 与 10/1 渠道改革（裁撤20%渠道+统一价）形成「产品+渠道」同步落地：一口价策略下订单质量 > 数量
- 判断：iX3 26.99万一口价是德国豪华在中国纯电价格带的「锚」——[[mercedes-benz]] 纯电GLC 24.9万被迫下探至同区间，BBA 纯电自相残杀开始（见 [[bba-ev-ranking-2026]]）

## 2026-10-06 更新：Neue Klasse 电池工厂投产 + 缺席巴黎车展
- **Irlbach-Straßkirchen 电池工厂投产**（约 10亿欧元），专供慕尼黑 i3——Neue Klasse 本土电池闭环
- **慕尼黑第 100 万辆 M3 下线**——燃油性能图腾收官叙事
- **缺席巴黎车展**：与 [[volkswagen]]、[[renault]]、[[mercedes-benz]] 全阵容参展形成反差——资源押 Neue Klasse 量产爬坡而非车展叙事（对照 [[2026-paris-auto-show]]）
- 判断：电池本土化+缺席车展 = 「中国+新世代」优先，欧洲投入收缩

## 2026-10-07 更新：砍 20% 部门与岗位 + 利润率目标
- **裁撤约 20% 部门与岗位**（德国约 8,000 岗位）——Neue Klasse 转型期组织收缩，与「缺席巴黎车展、资源押量产爬坡」（10/6）同向
- **2028 年利润率目标 3%-5%**——显著低于豪华品牌历史水平，反映电动化转型期利润率中枢下移的现实定价
- 判断：宝马「收缩+聚焦」组合拳（渠道裁 20%/部门裁 20%/缺席车展）= 德系豪华转型期标准动作；风险是收缩过头伤及品牌与研发（对照 [[mercedes-benz]] 多线并行、[[bba-ev-ranking-2026]]）

## 2026-10-08 更新：新3系 G50（燃油）+ iX4 定档年底
- **新3系 G50 燃油版**：直六 443 马力、零百 4.1 秒——燃油性能图腾续命（对照 10/7 裁 20% 部门）
- **iX4 定档年底**（Neue Klasse 平台）——新世代纯电补位
- 判断：双轨策略（高端燃油续命 + 新世代纯电补位）与「收缩+聚焦」（10/7）并行不悖；iX4 是 Neue Klasse 量产爬坡的第一份答卷（[[2026-paris-auto-show]]、[[bba-ev-ranking-2026]]）
