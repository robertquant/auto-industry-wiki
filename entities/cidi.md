# 希迪智驾 (CiDi)

## 概述
长沙智能驾驶研究院（CiDi / 希迪智驾），中国 L4 级自动驾驶公司，聚焦**商用车与矿区物流场景**，与[[pony-ai]]（干线物流重卡）、[[jiushi-intelligence]]（无人物流配送）路线互补。「车路协同 + L4 商用车」是其差异化标签，与[[autonomous-logistics-vehicle]] 商业化主线同向。

## 2026-11-24 L4 无人重卡 Vega 发布（宝马展）
- **Vega 为国内首款锚定 GB 44721-2026 强制国标的前装 L4 无人重卡**——不是后装改装、不是演示样车，按强制国标正向开发（[[l3-mandatory-standard]]）
- **「一车双模」**：同一平台覆盖无人干线运输 + 有人监督运输两种运营模式，兼顾法规过渡期与规模化运营
- 首台车 11/9 西安下线；11/24 宝马展发布
- 判断：与[[pony-ai]]×三一重卡路线对照——L4 重卡竞争从「算法演示」进入「国标合规 + 前装量产」阶段，成本曲线而非算力堆料决定规模（[[l4-global-race-2027]]）
