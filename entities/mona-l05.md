# 小鹏MONA L05

小鹏 MONA 系列第三款车型、**首款大五座中型 SUV**（4870/1930/1636mm、轴距 2940mm），2026-10-15 开启预售（16.98-19.18 万），10/29 广州上市。MONA 品牌从 M03 的「颜值+价格」打法升级为「算力批发」路线的新载体。

## 关键配置
- **智驾**：双图灵芯片 1500TOPS + 第二代 VLA + 车位到车位 2.0——20 万内价位带首个双自研芯片方案（对照 [[li-auto-m100]] 单芯 1280 TOPS）
- **座舱**：天玑 AIOS 6.2.0
- **动力**：纯电版 CLTC 535/635km；增程版（1.5L 增程器 + 37.2kWh 电池）纯电 237-253km、综合续航 1310km——MONA 品牌首次引入增程（呼应 [[range-extender-trend]]「大电池小油箱」主线），双动力并行
- **定价带**：16.98-19.18 万，与 M03 Ultra SE（15.18 万）形成 15-20 万双锚

## 战略判断
- 「算力批发」路线成型：双图灵 1500TOPS 下放至 16.98 万起——[[xpeng]] 把自研芯片量产红利直接转化为价格带降维，对标 [[deepal]] 华为智驾下放 15 万级的同类动作（[[lidar-penetration]]）
- 与 [[mona-l03]]（14.38 万起）构成 MONA 三档矩阵：L03 入门 / M03 走量 / L05 智驾旗舰
- 增程+智驾组合 = 小鹏从纯电单一动力向「智驾溢价 × 增程走量」双轮切换，直接对手含 [[li-auto]] 增程基本盘

## 2026-10-28 更新：产线首 5000 台下线，10/29 广州上市
- **产线首 5000 台完成下线**（10/28 晨报口径），**10/29 广州正式上市**（与 MONA WORLD 5000 人车主派对同步）——预售 16.98-19.18 万、5 款配置
- **品类修正**：L05 为 MONA 系列首款**大五座中型 SUV**（4870/1930/1636mm、轴距 2940mm，后备厢 702L/放倒 1913L），非轿车——10/16 页面初版「第二款轿车」描述有误，以 10/26-28 多源（汽车之家/新浪）修正
- 配置细节：17.3 英寸后排娱乐屏、Master Agent 超级智能体、小鹏 NGP 图灵 AI 智驾、DCC 可变阻尼减振器、标配 102L 前备厢
- 判断：大五座 SUV 品类 + 增程引入 = 小鹏用 MONA 品牌直接切 15-20 万家用 SUV 市场（对阵 [[deepal]] S07、[[li-auto]] 增程走量盘）；「产线 5000 台下线 → 次日上市」= 产能爬坡前置，上市即交付节奏

## 2026-10-30 更新：正式上市 13.98 万起
