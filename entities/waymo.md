# Waymo

## 概述
Alphabet 旗下 L4 自动驾驶公司，全球 Robotaxi 运营实绩的绝对领先者：~4,000 台车队、~50 万单/周、15 城运营。2026 年从股权融资转向债务融资，并启动欧洲、日本扩张——Robotaxi 竞争从「融资竞赛」进入「市场扩张竞赛」。

## 关键事实与时间线

| 时间 | 事件 |
|------|------|
| 2026-02 | 完成 160 亿美元股权融资，估值 **1260 亿美元**（≈8457 亿元人民币） |
| 2026-09 | ~4,000 台车队 / 周 50 万付费订单 / 15 城（见 [[waymo-vs-tesla-robotaxi-2026]]） |
| 2026-10-08 | **首次债务融资 50 亿美元**：用于 Robotaxi 扩张 + 入局欧洲、日本 |

## 2026-10-08 更新：50 亿美元贷款的战略含义

- **融资方式切换**：从股权输血（160 亿）转向债务融资——可解读为 Alphabet 收紧股权注资信号，Waymo 需自证单位经济
- **地理扩张**：欧洲 + 日本 = 中美之外第二战场——直接压缩中国 Robotaxi（[[xiaopeng-yoyo]]、[[pony-ai]]、百度萝卜快跑）的出海窗口期
- **全球三方格局**：Waymo（美国运营实绩）× Tesla Robotaxi（美国规模叙事，[[tesla]]）× 中国厂商（前装量产+软硬一体）——见 [[waymo-vs-tesla-robotaxi-2026]]
