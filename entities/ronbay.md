# 容百科技 (Ronbay)

## 概述

中国正极材料头部企业（高镍三元龙头），2026 年切入钠电正极并锁定最大单一客户宁德时代：**2026-10-15 公告，2026-2031 年供应宁德时代约 60% 的钠电正极采购量，预计合计供应金额超 1200 亿元**。

## 关键事实

| 维度 | 信息 |
|------|------|
| 公告日期 | 2026-10-15 |
| 客户 | [[catl]]（宁德时代） |
| 锁定份额 | 宁德钠电正极采购量约 60% |
| 期限 | 2026-2031 年（6 年） |
| 预计金额 | 超 1200 亿元 |
| 产品 | 钠电正极（[[sodium-ion-battery]] 关键材料） |

## 行业意义

- **钠电供应链从「技术验证」进入「长协锁量」阶段**：1200 亿级锁单意味着宁德在锂价高位（[[lithium-price-surge-2026]]）环境下为钠电路线锁定确定性供应，钠电从「储能补充」向「车用可选」爬升（[[sodium-ion-battery]]）
- **正极材料格局变动**：容百以三元龙头身份吃下钠电正极大单，与高镍主业形成「锂钠双轨」——材料厂在电池厂主导的供应链中通过技术卡位换取长协地位
- 与宁德 9 月收购耀宁电池工厂（[[catl]]）同构：宁德的垂直整合与生态锁定双向并行——上游锁材料、横向并产能
