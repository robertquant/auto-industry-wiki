# 蜂巢能源 (SVOLT)

中国动力电池厂商，脱胎于[[great-wall]]（长城汽车）电池事业部，2018 年独立运营。长城与魏建军关联方的核心电池供应商（2026 前三季长城向其采购 88.43 亿元、全年上限上调至 169 亿，见 [[great-wall]]）。**2026-10 龙鳞甲半固态电池包量产 = 混合固液路线从「验证」进入「量产」的标志性事件。**

## 龙鳞甲半固态电池包（2026-10-29 盖世晚报）

| 维度 | 参数 |
|------|------|
| 构型 | 半固态（混合固液） |
| 容量 | 100kWh |
| 电压 | 900V |
| 倍率 | 6C |
| 补能 | 12 分钟补能 500km |
| 量产状态 | 电池包量产下线 |

- **杨红新（蜂巢能源董事长）判断**：「混合固液长期主流」——全固态仍需突破循环寿命/界面阻抗，半固态以「成本可接受 + 性能跃迁」卡位量产窗口（路线对照见 [[solid-state-battery]]）
- **行业意义**：继 [[guangwan-jiyan]]（巨湾技研，10/13 固态产线投产）之后，「半固态量产元年」信号再强化；900V/6C 的「电压+倍率」双高规格直接服务超充补能（[[ultra-fast-charging]]）

## 与长城的关系

- 长城系「垂直整合」在电池侧的落点：早期车规电池自供（欧拉/魏牌/坦克），现扩展至半固态路线卡位
- 关联交易规模持续扩大（前三季 88.43 亿元采购）——车企与电池厂「血缘绑定」样本（对照 [[battery-white-box]] 车企穿透供应链趋势）

## 判断

- 蜂巢的「混动/固液共存」路线与宁德/比亚迪供应链出身的厂商形成差异化：不赌单一化学体系，以「PACK 定义能力 + 半固态先发」卡位 2027-2030 高端纯电补能叙事
- 车企自制 PACK 份额过半（2026-10）背景下，蜂巢作为独立电池厂的价值锚点在「前瞻技术（半固态）+ 规模化代工」而非单纯产能（[[battery-white-box]]）
