# 地平线 (Horizon Robotics)

## 概述
中国智驾芯片龙头，2026年征程系列累计量产突破1500万片，市占率13.6%居国产第一。从征程（智驾芯片）向星空（舱驾融合）双线扩张，是[[volkswagen]]合资公司酷睿程的技术底座。

## 10/5 补充：自主品牌份额登顶 + 规模化里程碑

| 维度 | 数据 |
|------|------|
| 2026 H1 自主品牌智驾芯片份额 | **31.94%（第一）** |
| 征程累计量产 | 1500万套 |
| 车型定点 | 近500款 |
| 搭载车辆 | 超800万辆 |
| 累计行驶里程 | 超千亿公里 |

**判断**：规模即壁垒——千亿公里真实场景数据直接喂养端到端训练（见 [[training-loop]]、[[data-moat]]），31.94% 份额意味着地平线已从「国产替代选项」变成「自主品牌默认底座」；10/21-23 世界智能网联汽车大会（亦庄）是 1500 万套后价格战是否开打的首个观察窗

## 星空6系列 — 中国首颗5nm舱驾融合芯片

| 维度 | 参数 |
|------|------|
| 工艺 | 5nm（中国首颗舱驾融合） |
| 星空6 (Starry 6) | 首颗5nm舱驾融合，对标SA8797 |
| 星空6P | 650 TOPS（高性能版） |
| 整车空间 | 官方口径空间占用-50% |
| 单车降本 | 1,500-4,000元 |
| 量产节奏 | 最快2026 Q3，首发客户 iCAR |
| 安全架构 | 「城堡」物理隔离（座舱/智驾域隔离） |

**判断**：星空6对标高通 SA8797（1280 TOPS）正面竞争——高通算力翻倍至1280TOPS后，星空6P的650TOPS面临直接的算力差距。卖点是「国产5nm+降本+白盒」，直接受益于舱驾融合爆发期（详见 [[cabin-drive-integration]]）。

## 与大众合资：酷睿程 (CARIZON)

- 2026年9月升级：AI基座大模型「白盒」合作
- 落地：2026 Q3起7款大众新车搭载，2027 H2交付L3
- 意义：从芯片供应升级为「芯片+大模型白盒」深度绑定——这是[[volkswagen]]中国智能化的技术主线

## 2026-10-12 更新：铃木定点——征程首次进入日系车企

- **[[suzuki]] e-Sky（11/16 日本上市）搭载征程芯片 + [[byd]] LFP 电池**——征程系列首次进入日系 OBM 量产车型，国产智驾芯片突破「日系保守供应链」的标志性事件
- 同日口径复核：2026 H1 自主品牌智驾芯片份额 **31.94%（第一）**、征程累计 1500 万套 / 800 万辆搭载；4 月智驾域控芯片装机英伟达 50.9% vs 地平线 13.6%（[[autonomous-driving-chips]]）
- 判断：铃木定点验证「国产芯片 + 中国电池」打包出海模式渗透到日系成本敏感型车企——地平线的客户结构从自主品牌（[[byd]]/理想/大众酷睿程）扩展到日系，[[battery-white-box]] 视角下中国供应链「系统级出海」再下一城

## 2026-09-28 更新：市占率新口径（9/15）

- **征程系列累计量产 1,500万颗**（2026-09-15 确认，与既有「1500万片」口径一致）
- **31.94% 市占率超英伟达**（2026年9月行业信源口径；与既有 13.6%〔2026 H1，国产第一〕存在**统计口径差异**——31.94% 或为征程系列在国产/特定市场的份额口径，两口径并存待核）
- 官方强调「征程系出货增速」：国产替代在 2026 H2 显著加速（对照：英伟达 50.9% 主导地位被持续侵蚀，见 [[autonomous-driving-chips]]）

## 2026-10-15 更新：8月装机——与英伟达差距缩至 10.4pp（红星资本局 10/14）

- **2026 年 8 月智驾芯片装机**：英伟达 **30.2%** vs 地平线 **19.75%**——差距从 35.8pp 缩至 **10.4pp**，**连续 6 个月装机环比正增长**
- 注：与前序口径并存（4 月域控芯片英伟达 50.9% vs 地平线 13.6%，见 10/12 条目）——不同统计口径（装机芯片 vs 域控）下国产替代斜率一致
- 判断：10.4pp 是国产龙头与英伟达的历史最小差距；「征程6系列放量 + 酷睿程/VCTC 定点」双引擎下，2026 Q4 是冲击 25%+ 份额的关键窗口（[[autonomous-driving-chips]]、[[nvidia]]）

## 2026-10-20 更新：星空6P获工博会CIIF大奖 + 单征程6M量产双节点

- **星空6P（BPU 650 TOPS）获工博会 CIIF 大奖**：智驾/座舱/仪表/车控**四域单芯片**，与新一代舱驾融合 OS 同获（[[starry-sky-chip]]、[[cabin-driving-fusion]]）——从 6/16 发布到国家级工业展奖项背书
- **单征程6M 城市NOA 方案量产首发**（[[qingzhou]] 首发，9 款合作车型，10-20 万价格带，10/20 盖世）——征程6 系列走量兑现
- 判断：「**征程走量、星空定调**」双线闭环成型：6M 吃掉 10-20 万平权红利（[[city-noa-penetration]]）、6P 卡位旗舰四域融合——与 [[blacksesame]] 武当C1296、[[snapdragon-8797]] 的舱驾融合竞争进入量产兑现阶段（[[cabin-drive-integration]]）

## 2026-10-29 更新：德国总统合肥体验 + 酷睿程 HS8 全自研口径
- **德国总统访问合肥体验地平线×大众酷睿程智驾**（Q3 起装大众在华 7 款纯电）——合资智驾获德国国家级背书（[[courizon]]、[[volkswagen]]）
- **酷睿程 HS8 = 首款全自研 L2++**（10/28 技术日口径）——酷睿程叙事从「白盒基座授权」升级「自研」，独立技术人格增强（[[courizon]]）
