# 比亚迪大汉（2026款）

## 概述
比亚迪王朝网旗舰轿车，2026年10月13日上市（9月成都车展首秀、预售 24.99-29.99 万）。定位从早期「挑战百万级」口径修正为 **D级行政轿车打 25 万级**——「尺寸越级+价格降维」打法的旗舰版本（见 [[byd]] 10/2 记录）。

## 上市配置（2026-10-13）

| 维度 | 内容 |
|------|------|
| 起售价 | **23.59 万元**（预售 24.99-29.99 万，上市价下探 1.4 万） |
| 续航 | CLTC 最高 **1008 km** |
| 电池 | 二代刀片电池（[[gen-2-blade-battery]]） |

| 尺寸 | D级行政（轴距 3,130mm） |
| 平台 | 全栈 800V（[[800v-platform]]） |

## 战略意义
- 王朝旗舰换代，卡位 Q4 冲量（王朝网第 1,000 万辆下线同期，见 [[byd]]）
- 云辇-A + 后轮转向全系标配 = 旗舰技术下放走量，直插传统豪华行政轿车（奥迪A6L/宝马5系）腹地（[[bba-ev-ranking-2026]]）

## 判断
1. 23.59 万起 + 1008km + 后轮转向全系标配——同价位无直接对手，验证比亚迪「配置越级+定价降维」的王朝打法
2. 国内弱盘（10月上旬零售 -24%，见 [[chinese-oem-export]]）背景下，旗舰车型承担「稳基盘+树标杆」双重任务——增量靠海外、结构靠旗舰
