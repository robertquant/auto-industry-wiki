# 上汽通用 (SAIC-GM)

## 概述
上汽集团与通用汽车合资公司，成立于1997年。2026年8月5日续约20年至2047年，从"技术承接端"转向"创新策源地"，新能源渗透率达两成，在主流合资车企中排名第一。

## 2026年续约要点

| 维度 | 内容 |
|------|------|
| 续约时间 | 2026年8月5日 |
| 延长期限 | 20年（至2047年） |
| 战略转向 | 由中国定义、研发、制造产品服务全球 |
| 定位变化 | 技术承接端 → 创新策源地 |
| 股东态度 | 全面强化资源倾斜，聚焦电动化转型、本土化研发、海外业务拓展 |
| 通用高管表态 | "在中国为中国，将中国经验带到全球" |

## 新能源转型进展

| 维度 | 数据 |
|------|------|
| 2026上半年新能源销量 | 近5万辆 |
| 同比增长 | +81% |
| 新能源渗透率 | 约20% |
| 合资车企排名 | 第一（主流合资） |

## 国产Tier1支撑出口

2026年上半年中国汽车出口达531万辆（同比+53%），其中新能源出口242万辆。国产Tier1（宁德时代、地平线、汇川技术等）已通过AEC-Q100车规级认证，进入多家车企全球定点名单。采用国产Tier1方案可使单车BOM成本降低10%-15%。

## 战略判断

### 续约意义
- **合资模式延续**：中国汽车合资史最长续约之一
- **技术主导权转移**：从引进技术到反向输出
- **市场定位**：合资品牌新能源转型的标杆

### 挑战
- 新能源产品矩阵仍待完善
- 与自主品牌价格竞争激烈
- 智能化能力需加速追赶

## 2026-10-22 更新：通用 Q3 财报 + 中国 8 连盈 + XT5 PHEV 首发 Momenta R7
- **通用集团 Q3**：净收入 500 亿美元/净利 33 亿/EBIT 41 亿；全年指引上调 145-155 亿；追加 **200 亿美元回购**
- **中国连续 8 季度盈利、新能源占比超 60% 创新高**——合资续约至 2047（8/5 已录）后经营面持续验证（[[saic-gm]] 视角下的上汽通用）
- **凯迪拉克 XT5 PHEV = 首款交付即搭载 Momenta R7 世界模型的豪华混动 SUV**（大众 ID.ERA 8X 同款方案，[[momenta]]）——从 Q3 交付 9,000 辆的燃油/轻混 XT5 扩展出 PHEV + 世界模型版本
- 判断：「美国血统 + 中国智驾」已成高端品牌中国卖车的默认路径；智驾外包 [[momenta]] 成行业标准配方（[[foreign-automakers-chinese-ad]]）；通用把中国盈利再投资于回购而非新工厂——中国核心资产的利润奶牛定位固化（对照 [[tesla]] Q3 同期）
