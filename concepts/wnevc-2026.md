# 2026世界智能网联汽车大会（WNEVC 2026）

2026年10月21-23日在北京亦庄举办，[[fifteen-five-plan]]（智能网联新能源汽车「十五五」规划）发布后的首个行业大会，政策细则落地与行业时间表对齐的核心观测窗口。

## 官方口径数据（开幕日）
| 指标 | 数据 |
|------|------|
| L2 渗透率 | **70.5%** |
| NOA（城市导航辅助）渗透率 | **34.2%** |
| 智驾测试牌照 | 2万+张 |
| 开放测试道路 | 5.7万 km |
| 累计测试里程 | 2.2亿 km |
| L3 | 首批上路 |

## 高管时间表密集对齐（2027/2028）
- **长安赵非**（[[changan]]）：2027 L3 量产、2028 L4 商业化运营；天枢领航一段式端到端已量产，持国内首张 L3 正式号牌
- **大众奥博穆**（[[volkswagen]]）：L2++ 已部署，2027 L3 就绪——「交付模式」（delivery mode）叙事
- **一汽刘亦功**（[[faw]]）：「聚合智能」，汽车/机器人/飞行汽车技术通用性>70%，司南智驾 L2-L4，算力集群国产化率100%
- **钟志华**：AI 仿真效率提升 10-200 倍；商用车「1车1司机、2车组队」引导式自动驾驶，改写 2000 万卡车司机运营模式

## 判断
①官方口径首次同时给出 L2（70.5%）与 NOA（34.2%）渗透率——「有智驾」与「有高阶智驾」的差距 36 个百分点，即 2027-28 增量空间；②各厂 L3/L4 时间表收敛到 2027/2028，行业进入法规+商业化双验证期（见 [[l3-autonomous-driving]]）；③「交付模式」词汇（大众）标志叙事从「发布技术」转向「兑现量产」。与 [[chongqing-auto-forum-2026]]（6月重庆）形成年度双大会节奏：重庆定调 AI 变革，亦庄对表产量化时间表。

## 2026-10-23 补充：闭幕日（10/22-23）——「商业闭环」共识 + 政策三连发

### 智驾下半场锚定「商业闭环」
- **赵福全**：2026 年是自动驾驶真正拐点；**李斌**（[[nio]]）：落地指标归结为「**用户愿意付钱 + 安全性可量化**」；**何小鹏**（[[xiaopeng]]）：计划年内完成全国主要城市高精地图升级，智驾团队扩至 **3500 人**、年研发投入不低于 **45 亿元**；**曹旭东**（[[momenta]]）：提出「智驾摩尔定律」（四年百倍/年十倍，10/22 已录）——行业共识从技术验证转向**规模化盈利**

### 政策制度化落地（三连发）
- **工信部郭守刚**：长安/北汽首批 L3 附条件准入（2025.12）后，**第二批准入试点推进中**——「从能用向好用跨越」（[[l3-mass-production-2026]]）
- **「蓝绿灯」强标**：工信部五项强标征求意见，ADS 标志灯专用蓝绿色，**L3+ 必装、低阶禁装**（颜色拟定 10/21 已录，[[l3-autonomous-driving]]）——L3 从公告准入补上「路上辨识」环节
- **杨冬生（[[byd]]）**：真 L3 限定场景、2028 有希望；不限定场景 L4 需再迭代 1-2 年；**靳玉志（[[yinwang]]）**：L2+ 渗透率 70%、国庆华为智驾日均 8000 万公里、引望公开 170 亿公里数据

### 闭幕日增量事件
- **GM 企业级 AI**（[[gm-forward-2026]]）：整车开发周期减半目标；LMR 电池首样件前虚拟仿真 **30 万方案**、**1 个月概念→获批**
- **神行者 8**（[[shenxingzhe-8]]）：上市 12h 大定 5000 台（华为乾崑 ADS+宁德电池+高通芯片）
- **滴滴×广汽埃安**（[[didi-auto]]）：33 传感器硬件平台、全无人载客，广州/北京示范

### 闭幕日判断
①政策进入「制度化落地」：L3 准入扩容 + ADS 标志灯 + 准入新规（[[innovation-verification-regulation-2026]]）三连发；②大佬路线分歧定格：小鹏跳过 L3（技术乐观派）vs 比亚迪 L3 是门槛（工程务实派）vs 蔚来法规对表 2027.7.1；③GM 虚拟仿真 30 万方案 = 海外传统车企 AI 工程化提速实证（[[ai-engineering-2026]]）
