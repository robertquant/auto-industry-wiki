# 德国×英伟达主权AI合作（2026-10）

德国联邦政府与英伟达的主权AI合作项目，聚焦**物理AI**（工业/机器人/自动驾驶），2026-10-19 柏林「Invest in Germany」峰会由总理默茨与黄仁勋官宣。这是欧洲主权AI叙事下**首个以「物理AI+工业应用」为轴心、国家级采购美国算力**的样本。

## 关键事实

| 维度 | 内容 |
|------|------|
| 官宣时间 | 2026-10-19（柏林峰会，默茨×黄仁勋） |
| 规模 | 约10亿欧元级（德国联邦政府投入） |
| 核心设施 | 慕尼黑工业AI云：约1万枚GPU / 0.5 EFLOPS |
| 技术方向 | 物理AI底座——训练机器人、自动驾驶、工业高性能AI模型 |
| 产业伙伴 | 西门子、奥迪、Black Forest Labs 等 |
| 性质 | 主权级（联邦政府直接采购美国算力） |

## 战略解读

1. **欧洲「双线下注」算力**：雷诺用资本买中国芯片（[[xinhe-hangtu]]），德国用主权基金买美国算力——欧洲在智驾/物理AI算力上放弃自建追赶，直接站队两大算力阵营。对照 [[china-tech-reverse-export]] 的中国技术反向输出，欧洲在算力层反而加深对中美双重依赖
2. **物理AI成主权竞争新战场**：与 [[physical-ai]]、[[world-model]] 呼应——工业AI云不是通用云，而是面向机器人/自动驾驶的「物理世界模拟+训练」基础设施；[[nvidia]] 借此从「卖芯片」升级为「主权AI基础设施供应商」
3. **对车企的含义**：奥迪作为产业伙伴参与，是继 [[volkswagen]]（地平线酷睿程）、[[bmw]]/[[mercedes-benz]]（momenta）之后，德系第三条智能化路径——**买算力+用中国算法/芯片混合路线**，德系「欧洲本土AI供应链」叙事进一步弱化
4. **0.5 EFLOPS 的规模定位**：约1万枚GPU（H100/B200级）对训练级算力仍是「起步规模」——更接近工业应用推理/微调云，而非前沿模型训练；政治象征意义 > 技术领先意义
