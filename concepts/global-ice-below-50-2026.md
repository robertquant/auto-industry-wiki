# 全球汽油车份额跌破50%（2026）

## 概述
2026年上半年，**纯汽油车型占全球新车销量比例降至 49%**，首次跌破50%——较2021年的73%回落24个百分点。全球汽车市场进入「电气化过半」时代，这是行业结构性拐点的标志性数据。

## 关键数据

| 指标 | 数值 |
|------|------|
| 2026H1 纯燃油全球份额 | **49%**（首次跌破50%） |
| 2021年份额 | 73% |
| 降幅 | -24pct（5年） |
| 主要贡献者 | 中国 |
| 同期中国新能源零售渗透率 | **65.7%**（9月，乘联会口径） |

## 驱动因素

1. **中国是最大单一引擎**：中国新能源渗透率全球最高（见 [[nev-penetration-60-percent]]），单国销量足以拉动全球结构
2. **油电平价加速**：锂电池降本 + 超充网络完善（[[ultra-fast-charging]]），BEV/PHEV 总拥有成本反超燃油
3. **强混/插混补位**：纯燃油被混动蚕食而非只被纯电替代——「不是电车赢，是油车输」

## 结构性含义

- **外资品牌在华「边打边缩」**：全球份额数据对应中国合资体系的持续收缩（[[honda-china]]、[[volkswagen]] 在华新能源失速）
- **燃油供应链进入加速出清**：印证 [[ice-supplier-divergence]] 时间线判断（2024-2027 加速淘汰期）
- **政策与市场共振**：欧盟 2035 禁燃、中国「十五五」规划（[[fifteen-five-plan]]）与市场数据互为因果

## 判断
- 「49%」是上半年数据，下半年中国/欧洲销量结构下，全年大概率站稳 47% 以下——50% 分界线将成历史
- 警惕口径差异：部分统计将轻混（MHEV）计入燃油车，「纯汽油」口径已排除 MHEV，实为最保守口径——真实电气化程度高于此数
