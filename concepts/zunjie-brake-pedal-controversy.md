# 尊界V800刹车踏板断裂事件

> 华为系高端品牌（[[zunjie]]）第一场正面质量危机。2026-10-08 起连续发酵，资本市场以两连跌停定价。

## 事件时间线

| 日期 | 事件 |
|------|------|
| 10/08 | 懂车帝实测 3 台尊界 V800：**100km/h-0 紧急制动时刹车踏板支架被踩断** |
| 10/08 | 尊界官方回应：制动系统按高于国标 GB 21670-2025 / GB 7258-2026、行业标准 QC/T 788-2018 验证，实际使用未发生断裂；承诺优化设计 + **已交付用户免费升级** |
| 10/08 | 江淮汽车（尊界制造商）**跌停**，收 24.72 元 |
| 10/09 | 懂车帝再回应：网传「暴力测试」不存在，百公里刹停是标准测试工况，非极端 |
| 10/09 | 江淮**再度跌停**，收 22.25 元——两连跌停 |
| 10/09 | 广汽本田借势营销：雅阁踏板可承受 3000N 以上不断裂 |

## 三方角力

- **测试方（懂车帝）**：百公里刹停是行业标准工况；踏板支架结构性断裂指向设计冗余不足
- **官方（尊界/江淮+华为）**：国标/行标合规话术 + 「免费升级」补偿——免费升级等于**变相承认设计冗余不足**
- **资本市场（江淮）**：两连跌停 = 用脚投票，对「华为智驾安全溢价」叙事首次定价负面

## 深层含义
- 冲击华为智驾「安全溢价」叙事——尊界是华为智选车最高端产品（76.6-101.6 万），安全是百万级定价的根基
- 后续影响：巴黎车展（[[2026-paris-auto-show]]）问界全系登台节奏或受波及；华为系与传统豪华品牌（奔驰 V 级/雷克萨斯 LM，对标见 [[mercedes-benz]]）对标时「可靠性」话语权被削弱
- 对照：智驾事故归责体系（[[adas-liability-guarantee]]）下，硬件结构缺陷比软件失效更致命——产品责任清晰指向制造方
