# 吉利×蔚来换电联盟 (2026)

## 概述
2026年9月28日，[[geely]] 与 [[nio]] 宣布充换电全面战略合作：资本互持 + 统一标准共建。换电补能网络从「蔚来独扛」走向「双巨头平台化」，是2026年补能赛道最值得跟踪的结构性事件。

## 合作结构（2026-09-28）

| 方向 | 内容 |
|------|------|
| 吉利入股蔚来能源 | 以易易互联100%股权 + 6.4亿现金，持股 **30%** |
| 蔚来入股吉利浩瀚能源 | 反向持股 **10%** |
| 标准共建 | 统一 C 端换电标准（换电体系互通） |
| 蔚来网络规模 | 累计充换电站 **9,410座**（换电站 4,109座），行业第一 |

## 意义与判断

1. **换电从单点走向平台化**：蔚来不再独扛换电重资产，吉利（易易互联在营运车辆/出租车换电有积累）带来规模与B端场景；对标宁德时代巧克力换电 & 超充联盟，补能竞争进入「联盟 vs 联盟」阶段。
2. **资本结构创新**：以子公司股权+现金置换入股，规避巨额现金支出——吉利用「易易互联」换「蔚来能源30%」，本质是补能资产的一次重组合并。
3. **统一C端换电标准**是最大想象空间：若标准打通，换电网络将具备跨品牌通用性，直接冲击超充阵营的「各自为战」。
4. **风险**：蔚来能源估值、换电体系兼容（电池规格差异）、乐道/萤火虫与吉利浩瀚能源车型的标准落地节奏。

## 2026-09-29 更新：估值与时间表明确

- **蔚来能源投后估值约 160 亿元**（吉利以易易互联100%股权 + 6.4亿现金换 30% 股权，对应估值口径首次公开）。
- **吉利首款换电车型 2027 年推出**，接入蔚来换电网络——换电标准统一从「纸上共识」进入「车型落地」阶段。
- **蔚来能源 2030 年目标建成 1 万座换电站**（对比当前 4,109 座，未来四年翻倍以上）。
- 与「宁德时代巧克力换电 + 超充联盟」形成 **联盟 vs 联盟** 格局：补能竞争从企业级升级到生态级（见 [[battery-swap-vs-ultra-fast-charging]]）。
