# 新能源渗透率60%里程碑 (2026年)

## 里程碑演进

| 时间 | 渗透率 | 数据来源 |
|------|--------|---------|
| 2026年4月 | 61.4% | 乘联分会（零售） |
| 2026年7月（零售） | 64.5% | 乘联分会（零售） |
| **2026年8月（零售）** | **65.8%** | 乘联分会（零售，8月新能源~104万辆/大盘158万辆） |
| **2026年8月（中汽协）** | **60.6%** | 中汽协（含商用车，新能源164.3万辆） |
| 2026年7月（终端） | 63.4% | 乘联会终端销量 |
| 2026年1-6月 | 49.6% | 中国机械工业联合会（H1均值） |
| 2026年7月 | 55%+ | 中汽协（含商用车） |

**突破65%意味着**：新能源从「多数」进入「绝对主导」——8月大盘158万辆（环比+8.1%）回暖背景下渗透率仍创新高，油电分化不可逆。8月品牌销量明细见 [[2026-08-china-sales-battle]]。

### 2026年9月更新：纯电逼近50%大关
- **8月燃油车零售**：仅54万辆（同比-40%），纯燃油同比-45%
- **纯电占比**：8月达到45.3%，连续5个月超40%，年底有望突破50%
- **零售前十车型**：8月TOP10已**无极车上榜**（纯电4席+插混6席）
- **新能源出口**：8月出口101万辆（+65.3%），连续3个月破百万
- **中汽协口径渗透率**：8月60.6%——含商用车后数据仍创新高

**判断**：纯电突破45%是转折性信号——即便含大量插混的65%+渗透率已有共识，纯电单独逼近50%意味着「油电替代」从总量进入结构深化阶段。

## 驱动因素

### 油电分化加速
- 中东冲突→油价上涨→电车需求传导
- 高油价、政策调整、消费信心偏弱
- 国产插混车型起售价下探至10万级+免购置税，挤压合资燃油车生存空间

### 竞争格局
- 比亚迪7月销量41.92万辆，是主要合资品牌数倍
- 自主品牌新能源渗透率远超合资
- 日系份额从2020年23.1%跌至不足10%

## 判断

**这不是渐进替代，是结构性断裂**。63.4%-64.5%渗透率意味着：

1. **燃油车退场加速**：合资品牌燃油车基本盘急剧萎缩，新能源不可逆
2. **中国品牌主导权确立**：新能源领域，中国品牌已经掌握定价权和技术话语权
3. **出口新引擎**：7月新能源出口22.4万辆，巴西市场暴涨120%
4. **产业链重构**：油电转换不只是动力形式变化，是整个供应链、渠道、用户心智的重构
5. **K型分化加速**：零跑10万+ vs 蔚小理米3万档，头部效应显著
