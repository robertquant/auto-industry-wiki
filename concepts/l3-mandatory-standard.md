# L3强制国标 (GB 44721—2026)

## 概述
中国首部针对L3/L4级自动驾驶的强制性国家标准 GB 44721—2026 于2026年8月正式发布，从推荐性标准升级为强制性标准。责任主体从驾驶员向车企转移，高阶智驶商业逻辑从"概念营销"转向"刚性安全监管"。拟于2027年7月1日起实施。

## 2026年9月关键更新

### 智界RX获L3路测牌照
9月16日，[[huawei-auto]]智界RX正式获批L3级自动驾驶道路测试牌照，正在城市快速路等复杂道路开展实测。测试车搭载38个感知传感器（896线双光路激光雷达+3颗固态激光雷达），L3版预售价35.98万元起。测试场景覆盖交通信号识别、紧急避险、最小风险策略等七大场景。

**判断**：这是GB 44721-2026发布后首个获L3路测的重点品牌，标志着标准从纸面进入实测阶段。华为的「技术+法规」双校准已超前于竞争对手完成。

### 十五五规划确立自动驾驶安全基准
工信部等九部门联合印发的《智能网联新能源汽车产业发展「十五五」规划》首次将自动驾驶安全性能确立为正向基准目标：「搭载自动驾驶系统车辆的安全性能须大幅超越人类驾驶员」。详见 [[fifteen-five-plan]]。

### 关键细节：L2 车无法 OTA 升到 L3（2026-09-25）
- **硬件预埋是硬门槛**：L2 与 L3 的硬件冗余（传感器、算力、线控）不同，**L2 存量车无法靠 OTA 升级到 L3**。
- **影响**：存量车主吃不到 L3 红利，加剧「买新不买旧」；二手车市场将进一步分层（L2 车残值承压）。
- **判断**：L3 强制国标（2027/7/1 实施）+ 不可 OTA 升级 → L3 成为新车差异化刚需，而非软件订阅点。

## 行业信号：L3硬件预埋启动

- **鸿蒙智行舱内激光雷达大批装车**（[[huawei-auto]]）：L3硬件预埋的明确信号
- **上汽大众 ID.ERA 5S**（限时8.99万起）：大众全球首款城市NOA轿车——L3前夜传统巨头加速补齐智驾
- **智己启动「无方向盘」车辆测试**：配合 [[tesla]] Cybercab（9/3发布）验证线控底盘赛道

**判断**：距2027年实施只剩不到一年，头部玩家已进入「硬件预埋+能力储备」阶段，舱内激光雷达、线控底盘成为新的军备竞赛点。

## 核心要求

### 安全标准
| 维度 | 要求 |
|------|------|
| 驾驶人接管能力 | 系统必须实时判断 |
| 安全水平 | 对标"合格且专注的驾驶人" |
| 全生命周期档案 | 车企需建立"安全档案（Safety Case）"制度 |
| 车企责任 | 对自动驾驶系统安全终身负责 |

### 责任转移
- **原有模式**：驾驶员为责任主体（"驾驶员全责"）
- **新标准**：车企全生命周期安全主体责任
- **核心变化**：告别"驾驶员全责"旧模式，车企需对智驾系统全生命周期负责
- **影响**：
  - L3+车型研发成本上升（需预埋证据链、可追溯系统）
  - 车企法务/合规团队权重提升
  - 传统Tier1与主机厂责任边界重构
  - 智驾系统设计需优先考虑安全冗余

### 对行业的影响
1. **L3+车型研发成本上升**：需预埋证据链、可追溯系统，增加开发成本
2. **车企法务/合规团队权重提升**：安全合规从"技术问题"变为"法律问题"
3. **Tier1与主机厂责任边界重构**：传统供应关系下责任划分需重新定义
4. **智驾功能释放节奏可能放缓**：安全验证周期拉长
5. **A股智能驾驶板块异动**：标准发布次日，芯片、域控、线控底盘多股涨停

## 标准内容要点

| 要点 | 内容 |
|------|------|
| 标准编号 | GB 44721—2026 |
| 全称 | 《智能网联汽车 自动驾驶系统安全要求》 |
| 发布方 | 工信部 |
| 发布日 | 2026年7月30日/8月4日 |
| 实施日 | 2027年7月1日 |
| 覆盖级别 | L3（有条件自动驾驶）和L4（高度自动驾驶） |

| 试验体系 | 统一标准化试验场景 |
| 用户要求 | 使用告知、操作培训等配套要求 |
