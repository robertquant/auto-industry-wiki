# 新型电池产业"十五五"规划 (2026)

## 概述

2026年9月28日，工信部等**七部门**联合印发《新型电池产业发展"十五五"规划》——我国**电池领域首个国家级专项规划**。规划首次从国家层面为电池产业设定2030年技术路线与产业目标，标志电池竞争从「企业级产能竞赛」升级为「国家战略定调」。

## 核心目标（2030）

| 目标 | 内容 |
|------|------|
| 全固态电池 | 初步实现规模化应用 |
| 长寿命锂电池 | 循环寿命达 **15,000次** |
| 质量水平 | 头部企业缺陷率达 **PPB级**（十亿分之一） |
| 产业整合 | 明确支持企业**兼并重组**、培育世界一流企业 |

## 市场反应

- 规划发布次日（9/29）A股固态电池概念**涨停潮**，国轩高科、时代万恒等多股涨停。
- 机构判断：固态电池**产业化拐点渐近**，政策端首次确认2030年规模化时间表。

## 与既有政策的衔接

- 与《智能网联新能源汽车产业发展"十五五"规划》（[[fifteen-five-plan]]，9/11九部门）形成「整车+电池」双规划组合：整车规划锚定2030年世界汽车强国，电池规划锚定2030年全固态规模化。
- 电池规划叠加比亚迪全固态装车定档（[[solid-state-battery]]，2027首款量产车），政策-企业的时间表首次对齐。

## 判断

1. **政策在「锦上添花」而非「雪中送炭」**：液态电池已被二代刀片卷到CLTC 1100km（[[gen-2-blade-battery]]），全固态规模化2030目标并不激进——规划更重要的作用是给头部企业（[[catl]]、[[byd]]）兼并重组提供政策背书。
2. **兼并重组信号**：在产能过剩周期（见 [[lithium-price-surge-2026]] 库存口径修正），明确支持兼并重组 = 官方为行业出清定调，二线电池厂生存空间进一步收窄。
3. **PPB级缺陷率**是头部化信号：只有规模化+全自动化产线才能达到，实质是「良率门槛」排除中小玩家。
