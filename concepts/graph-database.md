# 图数据库

## 概述
图数据库是AI基础设施的关系推理引擎，基于图论原理存储实体及其关系，擅长多跳查询、路径分析和知识图谱构建。在车企AI应用中，主要用于零部件BOM管理、故障传播分析、用户关联网络等场景。

## 核心能力

| 维度 | 特性 |
|------|------|
| AI范式 | 符号主义（知识图谱） |
| 数据形式 | 三元组（实体-关系-实体） |
| 查询方式 | 图遍历、路径查询、模式匹配 |
| 核心优势 | 关系推理、逻辑约束、多跳查询 |

## 主流产品

| 产品 | 特点 | 适用场景 |
|------|------|----------|
| Neo4j | 市场份额第一、Cypher查询语言 | 企业级知识图谱 |
| Nebula Graph | 国产、分布式、高扩展 | 超大规模图存储 |
| TigerGraph | 实时图分析、并行计算 | 金融风控、推荐系统 |
| Amazon Neptune | 全托管、AWS生态集成 | 云原生应用 |
| ArangoDB | 多模型（图+文档+KV） | 混合数据场景 |

## 车企应用场景

### 1. 零部件BOM关系管理
- 零件→子件→供应商多级关系
- 快速追踪零部件来源和影响范围
- 召回场景下精准定位问题批次

### 2. 故障传播路径分析
- 系统→子系统→零部件故障传播图
- 根因分析：从症状追溯到根本原因
- 预测性维护：提前识别潜在故障链

### 3. 用户-车辆-服务记录关联
- 用户画像与车辆配置关联
- 服务历史多维度分析
- 个性化推荐（保养建议、配件推荐）

### 4. 供应链风险评估
- 供应商→零部件→车型三元关系
- 单点失效风险识别
- 替代供应商快速匹配

### 5. 知识图谱构建
- 技术文档结构化
- 概念关联推理
- 智能问答的后端支撑

## 2026年趋势

### Graph RAG 崛起
- **Graph RAG + Vector RAG 混合架构成为主流**
- 图数据库负责结构化知识推理
- 向量数据库负责非结构化语义检索
- 两者结合提升复杂问答准确率

### 车企落地案例
- 知识图谱+大模型=企业级AI问答
- 故障诊断知识图谱：从症状→原因→解决方案
- 合规知识图谱：法规→标准→检测项目联动

## 与向量数据库协同

| 场景 | 向量数据库 | 图数据库 |
|------|-----------|----------|
| "有哪些零件类似X？" | ✅ 语义相似推荐 | ❌ |
| "X零件失效会影响哪些系统？" | ❌ | ✅ 关系遍历 |
| "最近的故障案例和解决方法" | ✅ 模糊匹配 | ✅ 语义+关系组合 |
| "这个故障为什么发生？" | ⚠️ 可能不准 | ✅ 因果推理 |
